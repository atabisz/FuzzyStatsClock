## Spacing Scale

All spacing expressed as WPF Margin/Padding values. Declared tokens are values this phase introduces as new spacing — multiples of 4 only:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding within stats rows |
| sm | 8px | Compact row margin within SettingsWindow sections (e.g. `Margin="0,8,10,0"`) |
| lg | 16px | Gap between Settings sections (e.g. `Margin="0,16,0,4"` before Battery Alert) |

Source: direct measurement from `SettingsWindow.xaml` existing section spacing.

Exceptions (pre-existing XAML values inherited unchanged — not new tokens introduced by this phase):
- Backdrop section heading top margin: `0,14,0,6` — matches the exact top-gap used before the two-column Grid in the Appearance tab, ensuring visual consistency. Value `14` is a pre-existing codebase constant, not a token this phase declares.
- StackPanel outer margin: `Margin="12"` on some Appearance tab StackPanels — pre-existing; not redeclared by this phase.
- BackdropBorder corner radius: `CornerRadius="5"` — matches `ContentBorder` CornerRadius. Source: CONTEXT.md (Claude's Discretion), resolved to harmonize with existing border.
- BackdropBorder padding: `Padding="0"` — BackdropBorder is a full-widget background layer, not a content container; no padding.

## Typography

All typography is defined in existing XAML and extended (not redefined) in this phase. New controls in SettingsWindow follow existing established sizes.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Widget phrase / stats label | 32px / 12px | Light (300) | 1.2 / 1.0 | PhraseText + CpuLabel/GpuLabel etc. — existing, unchanged |
| Settings controls | system default (~14px) | Regular (400) | 1.5 | All Settings TextBlocks, CheckBox Content, Slider labels, section headings |

**Weight note:** Settings section headings (e.g. "Theme", "Battery Alert", "Backdrop") use `FontWeight="SemiBold"` in XAML. This rendering is inherited from WPF ThemeMode="Dark" conventions and the existing pattern in `SettingsWindow.xaml` — it is not a separately declared project token. The project declares two weights: Light (300) for widget elements and Regular (400) as the Settings baseline. SemiBold on section headings is a ThemeMode-inherited rendering that the executor applies by following the existing `FontWeight="SemiBold"` XAML pattern, not a new token.

Source: `MainWindow.xaml` for widget sizes, `SettingsWindow.xaml` for Settings typography patterns.

New text introduced in this phase:
- Section heading: `"Backdrop"` — FontWeight="SemiBold", matching "Theme", "Battery Alert" headings (follow existing XAML pattern)

## Color

The widget uses a transparent overlay model. The Settings window uses WPF ThemeMode="Dark". Colors below cover both surfaces.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Transparent / `#01000000` | Widget background — hit-testable near-transparent; Settings window: system dark theme background |
| Secondary (30%) | `#FF2D2D2D` | Theme swatch cards in Settings; two-column Grid rows in Appearance tab |
| Accent (10%) | User-configurable (default white `#FFFFFFFF`) | PhraseText foreground, stat bar fills, date text (55% alpha accent), dial hands |
| Backdrop fill | `Color.FromArgb(alpha, 0, 0, 0)` | BackdropBorder and ContentBorder backgrounds on hover / always-visible — alpha computed from `BackdropOpacityPercent` |
| Destructive | none | No destructive actions in this phase |

Accent reserved for: phrase text foreground, stat bar fills (CpuBar/GpuBar/MemBar/PagBar/BattBar), date text foreground (55% alpha of accent), dial hand Stroke. Accent is NOT used for backdrop fill — backdrop is always black with variable alpha regardless of accent color.

Backdrop color semantics (source: CONTEXT.md):
- `BackdropBorder.Background` = `Color.FromArgb(BackdropAlpha(), 0, 0, 0)` when visible (hover or always-visible)
- `BackdropBorder.Background` = `Brushes.Transparent` when hidden
- Alpha formula: `(byte)Math.Clamp((int)(BackdropOpacityPercent / 100.0 * 255), 25, 255)`
- Default `BackdropOpacityPercent = 35` produces alpha `0x59` (89) — zero visual regression for existing users

Double-depth effect (locked decision from CONTEXT.md):
- Phrase/dial row: ContentBorder (alpha=BackdropAlpha) + BackdropBorder (alpha=BackdropAlpha) stacked = visually darker
- Date/stats/uptime rows: BackdropBorder only (alpha=BackdropAlpha) = lighter

## Interaction Contract

### BackdropBorder state machine

| Trigger | AlwaysVisible=false | AlwaysVisible=true |
|---------|--------------------|--------------------|
| App start / ApplySettings | Transparent | BackdropAlpha() fill |
| Window_MouseEnter (hover) | BackdropAlpha() fill | BackdropAlpha() fill (idempotent) |
| Ghost pre-activation cleanup | Transparent | Transparent (ghost wins) |
| Window_MouseLeave | Transparent | BackdropAlpha() fill (preserved) |
| Ghost Restored lambda | Transparent | BackdropAlpha() fill (preserved) |
| BackdropOpacitySlider drag | live update if hovering | live update always |
| ChkBackdropAlwaysVisible toggle ON | BackdropAlpha() fill | — |
| ChkBackdropAlwaysVisible toggle OFF | Transparent (if not hovering) | — |

Ghost mode (window Opacity=0) hides BackdropBorder with the entire window — no special handling required.

### Settings live-update behavior

`BackdropOpacitySlider` ValueChanged:
- Updates `BackdropOpacityLabel.Text` = `"{value}%"` on every tick
- Updates `BackdropBorder.Background` live only when backdrop is currently visible: `if (_backdropAlwaysVisible || _isHoverFastRefresh)`
- Updates `ContentBorder.Background` live under the same guard (so phrase area tracks proportionally)
- Calls `SaveSettings()` on slider release (not on every tick) — matches existing OpacitySlider pattern

`ChkBackdropAlwaysVisible` Changed:
- Immediately calls `ApplyBackdropState()` then `SaveSettings()`
- If checking (enabling): BackdropBorder becomes visible immediately
- If unchecking (disabling): BackdropBorder clears immediately (if not currently hovering)

### PopulateControls (SettingsWindow open)

```
BackdropOpacitySlider.Value  = snapshot.BackdropOpacityPercent
BackdropOpacityLabel.Text    = $"{snapshot.BackdropOpacityPercent}%"
ChkBackdropAlwaysVisible.IsChecked = snapshot.BackdropAlwaysVisible
```

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Not applicable — this phase adds settings controls, no standalone CTA button |
| Section heading | "Backdrop" |
| CheckBox label | "Always visible (not just on hover)" |
| Slider row label | "Opacity" |
| Slider value format | "{N}%" — integer, no decimal (e.g. "35%", "70%", "100%") |

- Slider label "Opacity" — matches the existing "Opacity" label for window opacity directly above; parallel naming reinforces they are both opacity controls at different scopes.
