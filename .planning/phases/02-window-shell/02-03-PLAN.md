  <name>Task 1: Human visual verification of transparent overlay window shell</name>
  <action>Launch the application and verify all 8 runtime behaviors as described in how-to-verify below.</action>
  <what-built>
    FuzzyClock.App — transparent WPF overlay window showing "half past 3" in white Segoe UI Light 32pt with drop shadow, positioned top-right of the primary monitor with 20px padding, always-on-top, no taskbar presence, single-instance enforced.
  </what-built>
  <how-to-verify>
    Launch the application:
      dotnet run --project FuzzyClock.App/FuzzyClock.App.csproj

    Verify each item:

    1. TRANSPARENCY: The text "half past 3" appears to float directly over the desktop wallpaper with no visible window border, title bar, or background rectangle. The wallpaper is visible through the gaps between letters.

    2. POSITION: The text is positioned at the top-right corner of the primary monitor, approximately 20px from both the right edge and top edge.

    3. DROP SHADOW: The text has a visible dark drop shadow providing contrast against both light and dark wallpapers. (If shadow appears too faint against a light wallpaper, note this — it can be tuned by adjusting DropShadowEffect parameters.)

    4. ALWAYS-ON-TOP: Open any other application (browser, file explorer, etc.) and click on it to give it focus. The "half past 3" text must remain visible over the top of all other windows.

    5. TASKBAR: The Windows taskbar at the bottom of the screen must show no button for FuzzyClock. No entry for the application should appear in the taskbar.

    6. ALT+TAB: Press Alt+Tab. The FuzzyClock overlay must NOT appear as an entry in the Alt+Tab window switcher.

    7. RIGHT-CLICK CLOSE: Right-click anywhere on the floating text (or the near-transparent area around the text). A context menu must appear with exactly one item: "Close". Click "Close" — the application must exit completely.

    8. SINGLE INSTANCE: Launch the application a second time (from a second terminal or by running dotnet run again). The second launch must exit immediately without showing a second overlay. Only one instance of "half past 3" should be visible at any time.

    Note: The text may appear slightly less sharp than normal application text. This is expected — Windows disables ClearType on transparent windows (DWM constraint). The drop shadow compensates for this. If the text is unreadably blurry rather than slightly soft, report it.
  </how-to-verify>
