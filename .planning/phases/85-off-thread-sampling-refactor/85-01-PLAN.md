<objective>
Introduce a pure-logic tickable seam (`SampleResult` struct, `GhostTransition` enum, `OnSampleTick` method) inside `GhostModeController` and refactor the existing `OnTimerTick` body to delegate all pure logic to it. **No threading changes in this plan.** Every observable behavior — ratio computation, modifier override, edge-only event emission, ghost activation at 1.0, WS_EX_TRANSPARENT removal below 1.0, `Restored` only at exactly 0.0 — must remain byte-for-byte identical. This unblocks Phase 87 tests and makes the Phase 85 threading swap (Plan 03) a thin wrapper.

Purpose: The pure seam is the single test-reachable artifact for sampler-core logic. Building it first — separate from the threading refactor — keeps the pure-logic change reviewable in isolation and eliminates "did the threading change break the logic?" as a question for later plans.

Output: `GhostModeController.cs` exposes `internal readonly record struct SampleResult`, `internal enum GhostTransition`, and `internal SampleResult OnSampleTick(int cursorX, int cursorY, int rectLeft, int rectTop, int rectRight, int rectBottom, bool modifiersHeld)`. The `OnTimerTick(object? sender, EventArgs e)` body is reduced to: gather Win32 inputs → call `OnSampleTick` → apply the result (event raises, `Activate()`, WS_EX_TRANSPARENT removal). All side-effecting branches happen post-seam, never inside it.
</objective>
