Add PAG counter support to StatsService.cs. Three sections to modify:

**1. Class fields** — add after the existing `private bool _gpuAvailable;` line:
```csharp

private bool _pagAvailable;
```

**2. Public property** — add after the existing `public float MemPercent` line:
```csharp
public float PagPercent { get; private set; } = -1f;  // -1f = unavailable sentinel (display "N/A")
```

**3. Initialize() method** — add after the `_memCounter` setup block (after the `// MEM is a point-in-time counter — no priming needed` comment line) and before `_gpuAvailable = ...`:

```csharp
_pagAvailable = PerformanceCounterCategory.Exists("Paging File");
if (_pagAvailable)
{
    try
    {
        // 4-param constructor required: "Paging File" is multi-instance.
        // DO NOT use the 3-param (string, string, bool) overload — it throws for multi-instance categories.
        // "% Usage" is a point-in-time ratio counter — no priming needed.
        _pagCounter = new PerformanceCounter("Paging File", "% Usage", "_Total", readOnly: true);
    }
    catch
    {
        _pagAvailable = false;
    }
}
PagPercent = _pagAvailable ? 0f : -1f;
```

Note: PagPercent init must appear BEFORE `_initialized = true` (the `_initialized = true` line must remain last).

**4. Refresh() method** — add after the `MemPercent = _memCounter?.NextValue() ?? 0f;` line and before the existing `if (!_gpuAvailable) return;`:

```csharp
if (_pagAvailable)
{
    try
    {
        PagPercent = _pagCounter?.NextValue() ?? 0f;
    }
    catch
    {
        _pagAvailable = false;
        PagPercent = -1f;
    }
}
```

**5. Dispose() method** — add after `_memCounter?.Dispose();` and before `DisposeGpuCounters();`:

```csharp
_pagCounter?.Dispose();
```

Critical: do NOT add a priming call (`_pagCounter.NextValue()` discard). "% Usage" is a ratio counter — it returns valid data on first call. Priming is only for rate counters (CPU, GPU).
