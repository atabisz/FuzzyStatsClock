  <action>
**AppSettings.cs — full rewrite:**

Replace the current positional record:
```csharp
public record AppSettings(double Left, double Top, int FontSize);
```

With an init-property record:
```csharp
// Source: official .NET 10 docs — System.Text.Json handles init-property records natively
namespace FuzzyClock.App;

public record AppSettings
{
    public double Left                 { get; init; } = -1;
    public double Top                  { get; init; } = 20;
    public int    FontSize             { get; init; } = 32;
    public bool   StatsVisible         { get; init; } = false;
    public int    StatsIntervalSeconds { get; init; } = 3;
}
// Left = -1 is the sentinel for "no saved position — use PositionTopRight() fallback"
```

Preserve the existing comment about `Left = -1`. Keep the `namespace FuzzyClock.App;` file-scoped namespace. No using directives needed (none were present before).

**SettingsService.cs — two targeted changes:**

1. Update `Defaults()` from positional construction to object-initializer syntax. Replace:
```csharp
public static AppSettings Defaults() => new(-1, 20, 32);
```
With:
```csharp
// Left = -1: sentinel for "no saved position"
public static AppSettings Defaults() => new()
{
    Left = -1, Top = 20, FontSize = 32,
    StatsVisible = false, StatsIntervalSeconds = 3
};
```

2. Add guard clause in `Load()` immediately after the `JsonSerializer.Deserialize` line. Replace:
```csharp
return JsonSerializer.Deserialize<AppSettings>(json) ?? Defaults();
```
With:
```csharp
var loaded = JsonSerializer.Deserialize<AppSettings>(json) ?? Defaults();
// Guard: StatsIntervalSeconds=0 means the field was absent in an old settings
// file or the file is corrupted. A zero-interval DispatcherTimer fires at
// maximum rate, causing a CPU spike. Replace with the safe default.
if (loaded.StatsIntervalSeconds <= 0)
    loaded = loaded with { StatsIntervalSeconds = Defaults().StatsIntervalSeconds };
return loaded;
```

Do NOT change `Clamp()` — the `with` expression `s with { Left = left, Top = top }` is fully compatible with init-property records and compiles unchanged.

Do NOT change `Save()`, the `FilePath` field, or any using directives.
