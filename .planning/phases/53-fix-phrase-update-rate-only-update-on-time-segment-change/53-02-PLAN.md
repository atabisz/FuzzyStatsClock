The key insight: check the segment key FIRST — if the bucket hasn't changed, skip `GetPhrase()` entirely (which avoids the random re-roll). Only call `GetPhrase()` when the key changes:

   ```csharp
   private void UpdatePhraseIfChanged()
   {
       string segmentKey = PhraseEngine.GetSegmentKey(DateTime.Now);
       if (segmentKey == _lastSegmentKey) return;  // same bucket — skip

       _lastSegmentKey   = segmentKey;
       string newPhrase  = PhraseEngine.GetPhrase(DateTime.Now);
       _currentRawPhrase = newPhrase;

       ApplyPhraseWrap(newPhrase);

       // Always update split TextBlocks (no cost if SplitPhrasePanel is Collapsed)
       var (qualifier, emphasis) = PhraseEngine.GetStructuredPhrase(DateTime.Now);
       QualifierText.Text = qualifier;
       EmphasisText.Text  = emphasis;

       // Force layout pass before repositioning
       UpdateLayout();
       // ... keep the rest of the existing method body unchanged (position guard, screen clamp, etc.)
   }
   ```

   IMPORTANT: Keep the entire block from `if (!_hasUserPosition)` through the end of the method exactly as-is. Only the top 3 lines (the guard and GetPhrase call) change. The old `if (newPhrase == _currentRawPhrase) return;` guard is removed — the segment-key guard replaces it.
