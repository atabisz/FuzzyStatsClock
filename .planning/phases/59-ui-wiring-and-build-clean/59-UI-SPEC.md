## Color

All values extracted from existing XAML and WPF ThemeMode="Dark". Phase 59 adds no color tokens.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `Transparent` / `#01000000` | Widget background — near-transparent to maintain hit-testing |
| Secondary (30%) | `#FF3A3A3A` / `#FF2D2D2D` | SettingsWindow segment rail backgrounds, theme card surfaces |
| Accent (10%) | User-configurable (default `#FFFFFFFF`) | Widget phrase text, stat bar fills, date text foreground |
| Destructive | not applicable | No destructive actions in this phase |

Accent reserved for: phrase text foreground, date text foreground, stat bar fill color, stat label/value text, DialCanvas hand stroke. Accent does NOT bleed onto the Nixie clock face — NixieClockView uses a hardcoded amber palette (`#FFFFC000` range) regardless of the user-selected accent color. This is an intentional design decision recorded in REQUIREMENTS.md Out of Scope.

Hover backdrop: `BackdropBorder.Background` is set to `Color.FromArgb(BackdropAlpha(), 0, 0, 0)` on mouse enter and `Brushes.Transparent` on mouse leave. After BACK-05, `ContentBorder.Background` remains at its XAML default of `Transparent` and is never set in code.

Source: `MainWindow.xaml` lines 22–31, 54, 76, 82; `SettingsWindow.xaml` lines 9, 276, 292; REQUIREMENTS.md Out of Scope

## Interaction Contract

### Clock Style Rail (SettingsWindow — Appearance tab)

Already implemented. Documented here as the contract record.

| State | Visual |
|-------|--------|
| Unselected button | Background Transparent, no border |
| Selected button | Background `#FF3C3C3C`, border `#FF666666` 1px, CornerRadius 3 |
| Hover on unselected | Background `#FF555555` |
| Rail container | Background `#FF3A3A3A`, CornerRadius 4, Padding 2 |

Clicking Nixie button fires `ClockTypeChanged` event with `ClockType.Nixie`, which causes `MainWindow` to hide PhraseText/DialCanvas/LcdView and show `NixieView`. This is already wired.

Source: `SettingsWindow.xaml` lines 13–48, 286–298

### Widget Hover Backdrop (MainWindow — BACK-05 target)

| Event | Before BACK-05 | After BACK-05 (target state) |
|-------|---------------|-------------------------------|
| Window_MouseEnter (normal) | BackdropBorder set + ContentBorder set | BackdropBorder set only |
| Window_MouseEnter (ghost cleanup) | BackdropBorder + ContentBorder both set Transparent | BackdropBorder only |
| Window_MouseLeave | BackdropBorder set Transparent + ContentBorder set Transparent | BackdropBorder set Transparent only |
| _ghostMode.Restored | ContentBorder set Transparent | No ContentBorder assignment |
| SetBackdropOpacityPercent | ContentBorder set + BackdropBorder set | BackdropBorder set only |

After BACK-05: `ContentBorder.Background` is `Transparent` (XAML default) at all times. `BackdropBorder` provides the complete hover backdrop for all widget rows including Row 0 (phrase/clock area).

Source: `59-CONTEXT.md` lines 25–37, `MainWindow.xaml` lines 28–31, 42–46
