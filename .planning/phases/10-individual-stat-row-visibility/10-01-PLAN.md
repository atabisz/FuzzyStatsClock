  <action>
In `FuzzyClock.App/AppSettings.cs`, add three new init-property bool fields after `StatsIntervalSeconds`:

```csharp
public bool CpuVisible { get; init; } = true;
public bool GpuVisible { get; init; } = true;
public bool MemVisible { get; init; } = true;
```

Follow the existing init-property pattern exactly (same style as `StatsVisible`). No migration guard
needed in `SettingsService.Load()` — `false` is never a dangerous default for row visibility unlike
the zero-interval case. Old settings.json files (without these fields) will deserialize using the
`= true` property defaults automatically.

In `FuzzyClock.App/SettingsService.cs`, update the `Defaults()` method to explicitly include the
three new fields for consistency with the existing explicit style:

```csharp
public static AppSettings Defaults() => new()
{
    Left = -1, Top = 20, FontSize = 32,
    StatsVisible = false, StatsIntervalSeconds = 3,
    CpuVisible = true, GpuVisible = true, MemVisible = true
};
```
