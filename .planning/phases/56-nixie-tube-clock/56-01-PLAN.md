  <action>
    Read SevenSegmentDigit.xaml and SevenSegmentDigit.xaml.cs verbatim first — NixieDigit mirrors this pattern exactly.

    **NixieDigit.xaml:**
    Single `&lt;Canvas x:Name="RootCanvas" ClipToBounds="True"/&gt;` inside the UserControl. No other XAML content — all geometry is built in code-behind.

    **NixieDigit.xaml.cs — DependencyProperties:**
    - `ActiveDigit` (int, default -1): calls `OnVisualPropertyChanged` on change
    - `DigitHeight` (double, default 56.0 Medium): calls `OnDigitHeightChanged` which calls `RebuildGeometry()` then `UpdateDisplay(ActiveDigit)`

    **RebuildGeometry() — build in this exact order inside RootCanvas.Children:**

    1. **Glass tube border:** A `Rectangle` with `RadiusX=8`, `RadiusY=8`, `Fill="#CC1A0800"` (very dark semi-transparent brown-black), `Stroke="#80FF8C00"` (half-alpha warm orange), `StrokeThickness="1.5"`. Width = digitW, Height = full canvas height. Add at index 0.

    2. **Glass highlight:** A narrow `Rectangle` at the top (height = canvasH * 0.18), `RadiusX=6`, `RadiusY=6`, same width, `Fill` = semi-transparent white `Color.FromArgb(0x14, 0xFF, 0xFF, 0xFF)` (~8%). This simulates glass curvature reflection.

    3. **Wire mesh overlay:** Horizontal `Line` elements spaced every 7px from `tubePad=4` to `canvasH - tubePad`. Each line: `X1=tubePad+2`, `X2=digitW-tubePad-2`, `Stroke=Color.FromArgb(0x18, 0xFF, 0x8C, 0x00)` (very faint orange), `StrokeThickness=0.5`. Draw after tube border, before ghost digits.

    4. **Ghost cathode TextBlocks:** 10 `TextBlock` elements, text = "0" through "9". FontFamily="Segoe UI", FontSize = digitH * 0.72, FontWeight=Bold. Each positioned in `RootCanvas` via `Canvas.SetLeft`/`Canvas.SetTop` so all digits are horizontally centered and vertically offset by `(digit_index * 1.5)` px from a base vertical center position within the tube. Store references in a `TextBlock[] _ghosts` field. Set `ClipToBounds=True` on RootCanvas.

    5. **Active digit glow ellipse:** An `Ellipse` stored as `_glowEllipse`, Width=digitW*1.1, Height=digitH*0.55, positioned behind the active TextBlock. `Fill` = `RadialGradientBrush` with GradientStops: center=`Color.FromArgb(0xA0, 0xFF, 0x8C, 0x00)` (63% warm orange), outer=`Colors.Transparent`. Add after ghost TextBlocks so it renders in front of ghosts but behind the active digit label. **DO NOT use DropShadowEffect or BlurEffect — forbidden under AllowsTransparency="True".**

    6. At end of `RebuildGeometry()`: set `RootCanvas.Width = digitW; RootCanvas.Height = canvasH; this.Width = digitW; this.Height = canvasH;` — exactly as SevenSegmentDigit does.

    **UpdateDisplay(int activeDigit):**
    - Ghost opacity tiers (set TextBlock.Foreground):
      - `|i - activeDigit| == 0`: `Color.FromArgb(0xFF, 0xFF, 0x8C, 0x00)` — full warm orange
      - `|i - activeDigit| == 1`: `Color.FromArgb(0x1E, 0xFF, 0x80, 0x00)` (~12%)
      - `|i - activeDigit| == 2`: `Color.FromArgb(0x18, 0xFF, 0x80, 0x00)` (~9.5%)
      - all others: `Color.FromArgb(0x14, 0xFF, 0x80, 0x00)` (~8%)
    - Position `_glowEllipse` at `Canvas.SetLeft/Top` centered behind the active TextBlock.
    - If `activeDigit == -1` (blank): set all ghosts to base ghost opacity, hide `_glowEllipse` (Visibility=Collapsed).

    **Dimension sizing:** digitW = digitH * 0.62 (slightly narrow, like real Nixie digit shapes). canvasH = digitH + 12 (padding above/below). These are starting values — the visual review checkpoint (Plan 03) tunes them.

    **NixieSize.cs:**
    ```csharp
    // FuzzyClock.App/NixieSize.cs
    using FuzzyClock.App.Controls; // or wherever LcdSize lives
    public static class NixieSizeMap
    {
        public static double ToDigitHeight(LcdSize size) => size switch
        {
            LcdSize.Small  => 40.0,
            LcdSize.Medium => 56.0,
            LcdSize.Large  => 72.0,
            _ => throw new ArgumentOutOfRangeException(nameof(size))
        };
    }
    ```

    Read LcdClockView.xaml and LcdClockView.xaml.cs verbatim first — NixieClockView mirrors this pattern exactly.

    **NixieClockView.xaml:**
    A `StackPanel` (Orientation=Horizontal) containing:
    - `NixieDigit x:Name="D0"` — tens of hours
    - `NixieDigit x:Name="D1"` — units of hours
    - A colon separator (see below)
    - `NixieDigit x:Name="D2"` — tens of minutes
    - `NixieDigit x:Name="D3"` — units of minutes

    **Colon separator:** Two `Ellipse` elements stacked vertically in a `StackPanel` (Orientation=Vertical, VerticalAlignment=Center). Each ellipse: Width=Height=8 (at Medium — set via binding or code), Fill=`RadialGradientBrush` same warm orange center-to-transparent. Margin between dots = 6. Float freely (no tube border — cleaner visual balance at all sizes per Claude's discretion). Store as `_colonDot1` and `_colonDot2` for size updates.

    **NixieClockView.xaml.cs — mirrors LcdClockView:**
    - `_timer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(1) }; _timer.Tick += (_, _) => UpdateTime();`
    - `IsVisibleChanged += OnIsVisibleChanged;` — starts timer when visible, stops when hidden (same as LcdClockView)
    - `Size` DependencyProperty of type `LcdSize` (default `LcdSize.Medium`): callback `OnSizeChanged()` maps to `NixieSizeMap.ToDigitHeight(value)` and assigns to `D0.DigitHeight = D1.DigitHeight = D2.DigitHeight = D3.DigitHeight = height`; also scales colon dot size proportionally (`dotSize = height * 0.13`)

    **UpdateTime():**
    ```csharp
    var now = DateTime.Now;
    int h = now.Hour % 12;
    if (h == 0) h = 12;  // 12hr: midnight/noon = 12
    int m = now.Minute;
    D0.ActiveDigit = h / 10;  // leading zero shows ghost "0" — authentic Nixie look
    D1.ActiveDigit = h % 10;
    D2.ActiveDigit = m / 10;
    D3.ActiveDigit = m % 10;
    ```

    **DO NOT** call `UpdateTime()` from the constructor or from any visibility-change handler — `IsVisibleChanged` fires the timer which calls `UpdateTime()` automatically. Same pattern as LcdClockView with the comment: "// Do NOT call UpdateTime() here — IsVisibleChanged fires automatically".

    Add the namespace declaration in NixieClockView.xaml:
    `xmlns:controls="clr-namespace:FuzzyClock.App.Controls"`
    so that `NixieDigit` elements resolve correctly within the same namespace.
