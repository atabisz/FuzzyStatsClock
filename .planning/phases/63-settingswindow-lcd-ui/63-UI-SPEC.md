## Typography

All text is rendered by WPF using the system default (Segoe UI). The following sizes are in
use across SettingsWindow and must be matched by the LCD options row.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body / labels | 12px (WPF default) | Regular (400) | 1.3 (WPF default) | Grid row labels, checkbox content, ComboBox items |
| Section header | 12px (WPF default) | SemiBold (600) | 1.3 | Section headings (e.g., "Backdrop", "Theme") |
| Small annotation | 11px | Regular (400) | 1.3 | Helper text (Foreground="#FF999999") |
| Theme card label | 10px | Regular (400) | 1.3 | Theme swatch captions |

**Source:** Extracted from SettingsWindow.xaml. No explicit FontSize on row labels or
checkboxes — they inherit WPF default (12px Segoe UI).

The LCD options row uses the default inherited size. No new font sizes are introduced.

## Color

This is a forced dark-mode window (`ThemeMode="Dark"`). All color values are locked by the
existing SettingsWindow design. The LCD row adds no new colors.

| Role | Value | Usage |

boxes, or the Clock Style rail.

Destructive: none in this phase. No destructive actions.

## Interaction Contract

### Visibility Gating (LCD-05)

Controlled in `SetClockStyleButtonStates(ClockType ct)`:

| Condition | LcdOptionsLabel | LcdOptionsPanel | DialFaceLabel | DialFacePanel |
|-----------|----------------|-----------------|---------------|---------------|
| ct == ClockType.Lcd | Visible | Visible | Collapsed | Collapsed |
| ct == ClockType.Dial | Collapsed | Collapsed | Visible | Visible |
| ct == ClockType.Phrase | Collapsed | Collapsed | Collapsed | Collapsed |
| ct == ClockType.Nixie | Collapsed | Collapsed | Collapsed | Collapsed |

**Source:** D-09, mirrors the DialFaceLabel/DialFacePanel gating pattern.

### Immediate Live Update (LCD-02, LCD-03, LCD-04)

All three controls fire their events immediately on change, outside `_suppressEvents`. The
events are consumed by MainWindow subscriptions (lines ~418–435) which update the live
widget without a settings save/reopen cycle.

| Control | Event fired | Consumed by |
|---------|-------------|-------------|
| ChkLcdUse24Hr | LcdUse24HrChanged(bool) | MainWindow.xaml.cs ~line 418 |
| ChkLcdShowSeconds | LcdShowSecondsChanged(bool) | MainWindow.xaml.cs ~line 424 |
| CmbLcdStyle | LcdStyleChanged(string) | MainWindow.xaml.cs ~line 430 |

### PopulateControls Additions (LCD-03 read-back)

Under `_suppressEvents = true`, add to `PopulateControls(SettingsSnapshot s)`:

```
ChkLcdUse24Hr.IsChecked    = s.LcdUse24Hr;
ChkLcdShowSeconds.IsChecked = s.LcdShowSeconds;
CmbLcdStyle.SelectedIndex  = s.LcdStyle switch { "Paper" => 1, "Silver" => 2, _ => 0 };
```

**Source:** D-10. Default falls through to Dark (index 0) for any unrecognized string.

### BtnLcd_Click Handler

```
if (_suppressEvents) return;
SetClockStyleButtonStates(ClockType.Lcd);
ClockTypeChanged?.Invoke(ClockType.Lcd);
```

**Source:** D-02. Exact mirror of BtnPhrase_Click, BtnDial_Click, BtnNixie_Click.

## Constraints and Non-Goals

- **No new colors.** The LCD options row uses only inherited WPF defaults and the existing
  secondary (#FF3A3A3A) container color for BtnLcd.
- **No new spacing values.** Row 6 spacing replicates Row 5 (DialFaceLabel/DialFacePanel)
  exactly: `Margin="0,8,10,0"` on label, `Margin="0,8,0,0"` on panel.
- **No MainWindow changes.** Event subscriptions for the three LCD events already exist in
  MainWindow.xaml.cs. This phase only wires the SettingsWindow side.
- **No new AppSettings fields.** LcdUse24Hr, LcdShowSeconds, LcdStyle all exist in
  AppSettings.cs with defaults (false, true, "Dark").
- **No new SettingsSnapshot fields.** Same three fields exist in SettingsSnapshot.cs.
- **ThemeMode="Dark" isolation.** SettingsWindow uses ThemeMode="Dark"; zero style leakage
  to MainWindow. No changes to MainWindow's visual layer.
