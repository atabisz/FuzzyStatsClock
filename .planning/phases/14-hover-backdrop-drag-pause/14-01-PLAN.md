**MainWindow.xaml — two changes:**

1. Add `x:Name="ContentBorder"` to the Border at Grid.Row="0" (the one that wraps the phrase/dial content). Currently:
   ```xml
   <Border Grid.Row="0"
           Background="#26000000"
           CornerRadius="5"
           Padding="6">
   ```
   Change to:
   ```xml
   <Border x:Name="ContentBorder"
           Grid.Row="0"
           Background="Transparent"
           CornerRadius="5"
           Padding="6">
   ```
   Rationale: `#26000000` is 15% black — always visible, which breaks the "invisible by default" goal. Transparent by default; code-behind drives conditional backdrop.

**MainWindow.xaml.cs — three changes:**

2. **Extend `Window_MouseEnter`** (currently only handles fast-refresh). The Phase 12 handler guards on `StatsPanel.Visibility != Visible` and timer state. Extend to set the backdrop AFTER the existing fast-refresh logic (so both effects happen together):
   ```csharp
   private void Window_MouseEnter(object sender, MouseEventArgs e)
   {
       if (StatsPanel.Visibility != Visibility.Visible) return;
       // Fast-refresh (Phase 12): accelerate stats timer
       if (_statsTimer != null && _statsTimer.IsEnabled)
       {
           _statsTimer.Stop();
           _statsTimer.Interval = TimeSpan.FromSeconds(0.5);
           _statsTimer.Start();
       }
       // Backdrop (Phase 14): show semi-transparent background when stats visible
       ContentBorder.Background = new System.Windows.Media.SolidColorBrush(
           System.Windows.Media.Color.FromArgb(0x59, 0, 0, 0));
   }
   ```
   Note: `0x59` = 89/255 ≈ 35% alpha. Do NOT return early if the timer is not running — the backdrop must show even when stats are visible but the timer has been stopped for some reason.

3. **Extend `Window_MouseLeave`** (currently only handles fast-refresh restore). Extend to restore transparent backdrop:
   ```csharp
   private void Window_MouseLeave(object sender, MouseEventArgs e)
   {
       if (StatsPanel.Visibility != Visibility.Visible) return;
       // Fast-refresh restore (Phase 12): restore configured interval
       if (_statsTimer != null)
       {
           _statsTimer.Stop();
           _statsTimer.Interval = TimeSpan.FromSeconds(_statsIntervalSeconds);
           _statsTimer.Start();
       }
       // Backdrop restore (Phase 14): always return to transparent on leave
       ContentBorder.Background = System.Windows.Media.Brushes.Transparent;
   }
   ```

4. **Guard `Grid_MouseLeftButtonDown`** with timer stop/start around `DragMove()`:
   ```csharp
   private void Grid_MouseLeftButtonDown(object sender, MouseButtonEventArgs e)
   {
       // Pause stats during drag — DragMove() is a blocking Win32 modal loop.
       // Stop timer before, restart after if it was running (don't start it if stats are hidden).
       bool statsTimerWasRunning = _statsTimer?.IsEnabled ?? false;
       if (statsTimerWasRunning) _statsTimer!.Stop();

       DragMove();
       // LocationChanged fires during DragMove — _hasUserPosition is already true here.

       if (statsTimerWasRunning) _statsTimer!.Start();
       SaveSettings();
   }
   ```
   Note: Only restart if it was running — this prevents accidentally starting the timer when stats are hidden. The `!` null-forgiving operator is safe here because `statsTimerWasRunning` can only be true if `_statsTimer` is non-null.

**Add required using at top of MainWindow.xaml.cs** if not already present:
   - `System.Windows.Media` — needed for `SolidColorBrush`, `Color`, `Brushes`. Check existing usings first; WPF projects often have this via implicit usings or existing code. If `SolidColorBrush` is not currently used directly in the file (it may be used in XAML only), add the using.
