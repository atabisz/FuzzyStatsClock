## Component Specifications

### StatsIntervalSlider (Continuous Slider)

**Layout:** Grid row replacement for existing CmbStatsInterval (§450-462)

```
Grid.Row="1" Grid.Column="1" (inherits existing ComboBox position)
StackPanel Orientation="Horizontal" (container for slider + label)
```

**Slider properties:**
- `Minimum="0.5"` (STAT-01 requirement: 0.5-10.0s range)
- `Maximum="10.0"`
- `SmallChange="0.1"` (keyboard arrow key increment, supports 1-decimal precision per STAT-04)
- `LargeChange="1.0"` (page up/down increment, 10% of 10s range)
- `TickFrequency="0.5"` (visual tick spacing for reference)
- `IsSnapToTickEnabled="False"` (continuous selection, not locked to ticks per D-02)
- `Width="160"` (consistent with all existing sliders)
- `VerticalAlignment="Center"`

**Value label properties:**
- `x:Name="StatsIntervalLabel"`
- `Width="42"` (matches GhostFadeRadiusLabel width for 5-6 character strings)
- `VerticalAlignment="Center"`
- `Margin="6,0,0,0"` (inline-gap spacing)

**Event handler:**
- `ValueChanged="StatsIntervalSlider_ValueChanged"`
- Handler pattern: `_suppressEvents` guard → `Math.Round(e.NewValue, 1)` → update label text → fire `StatsIntervalChanged?.Invoke(val)`

**Source:** Pattern replicated from GhostFadeRadiusSlider (§535-542), adapted for 0.5-10.0 range and 0.1 increment.

### Visual States

| State | Visual Presentation |
|-------|---------------------|
| Default | Slider thumb at current value position; label shows "{value:F1}s" |
| Hover | WPF default slider thumb hover highlight (system theme) |
| Dragging | WPF default slider thumb pressed state; label updates in real-time as thumb moves |
| Disabled | Slider + label gray out when ChkStatsVisible is unchecked (not part of Phase 71 scope, but document for consistency) |

**Interaction flow:**
1. User drags slider thumb OR uses arrow keys/page up/page down
2. ValueChanged fires on every value change
3. Math.Round(value, 1) enforces 1-decimal precision
4. Label text updates to "{roundedValue:F1}s"
5. StatsIntervalChanged event fires → MainWindow.SetStatsInterval(double)
6. MainWindow updates timer interval immediately (no save-and-restart required)

**Source:** Existing slider interaction patterns from OpacitySlider and GhostFadeRadiusSlider.

## Accessibility

**Keyboard navigation:**
- Tab: Focus on slider thumb
- Arrow keys: Increment/decrement by SmallChange (0.1s)
- Page Up/Down: Increment/decrement by LargeChange (1.0s)
- Home/End: Jump to Minimum (0.5s) / Maximum (10.0s)

**Screen reader:** WPF Slider announces value changes automatically. No custom AutomationProperties required.

**Contrast:** WPF dark theme slider provides sufficient contrast (tested in existing OpacitySlider, BackdropOpacitySlider, GhostFadeRadiusSlider).

**Source:** WPF Slider built-in accessibility features. No additional implementation needed.

## Validation & Persistence

**UI-side validation:** None required. Math.Round(value, 1) in ValueChanged handler enforces precision.

**Persistence-side validation:** SettingsService.Validate() (not part of UI contract, but documented for completeness):
- Range clamp: 0.5 ≤ value ≤ 10.0
- Precision round: Math.Round(value, 1)
- Default fallback: 2.0s (Decision D-01)

**Source:** RESEARCH.md §143-150 validation pattern.
