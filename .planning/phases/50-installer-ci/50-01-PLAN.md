Create `FuzzyClock.iss` at the repo root with the following exact structure:

**Preprocessor block** (top of file):
```
#ifndef AppVersion
  #define AppVersion "0.0.0-dev"
#endif
#ifndef SourceDir
  #define SourceDir "publish"
#endif
```
CI injects these via `/DAppVersion=X.Y.Z /DSourceDir=publish`.

**[Setup] section** with these exact values:
- `AppId={{B8F2E3A1-7C4D-4E5F-9A6B-1D2E3F4A5B6C}` (generate a stable GUID — use this one, never change it)
- `AppName=FuzzyClock`
- `AppVersion={#AppVersion}`
- `AppPublisher=Alex Tabisz`
- `DefaultDirName={localappdata}\Programs\FuzzyClock`
- `DefaultGroupName=FuzzyClock`
- `PrivilegesRequired=lowest` (per-user, no UAC)
- `OutputDir=installer`
- `OutputBaseFilename=FuzzyClockSetup-{#AppVersion}`
- `Compression=lzma2`
- `SolidCompression=yes`
- `AppMutex=FuzzyClock_SingleInstance_v1` (exact match to App.xaml.cs mutex name — case sensitive)
- `UninstallDisplayName=FuzzyClock`

**[Languages] section:**
```
Name: "english"; MessagesFile: "compiler:Default.isl"
```

**[Files] section:**
```
Source: "{#SourceDir}\FuzzyClock.exe"; DestDir: "{app}"; Flags: ignoreversion
```
Do NOT include `{localappdata}\FuzzyClock` in `[Dirs]` — the settings directory must survive uninstall.

**[Icons] section** (Start Menu shortcut):
```
Name: "{group}\FuzzyClock"; Filename: "{app}\FuzzyClock.exe"
```

**[Run] section** (finish page launch checkbox, checked by default):
```
Filename: "{app}\FuzzyClock.exe"; Description: "Launch FuzzyClock"; Flags: postinstall nowait skipifsilent
```
Do NOT add `unchecked` flag — checkbox defaults to checked per user decision.

**[Code] section** with Pascal script containing three procedures:

1. `CurStepChanged(CurStep: TSetupStep)` — on `ssPostInstall`, check if `HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` has a value named `FuzzyClock`. If it exists, rewrite it with `ExpandConstant('{app}\FuzzyClock.exe')`. This ensures the auto-launch registry entry points to the (potentially new) install path after upgrade.

2. `InitializeUninstallProgressForm()` — create a `TNewCheckBox` on `UninstallProgressForm` with caption `'Also remove my settings (settings.json)'`, `Checked := False` (preserve settings by default). Position it below `UninstallProgressForm.StatusLabel` with 8px gap.

3. `CurUninstallStepChanged(CurUninstallStep: TUninstallStep)` — on `usPostUninstall`, if `RemoveSettingsCheckbox` is assigned and checked, call `DelTree(ExpandConstant('{localappdata}\FuzzyClock'), True, True, True)` to remove the entire settings directory.

Variable declaration: `RemoveSettingsCheckbox: TNewCheckBox;` at module level in the [Code] section.

Reference the complete example in 50-RESEARCH.md "Complete Minimal FuzzyClock.iss Structure" section for the exact Pascal code patterns.
