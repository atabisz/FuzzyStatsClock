    2. Add a new private method `InitTrayIcon()` in the class (near OnClosing, before UpdateDialDisplay):
       ```csharp
       private void InitTrayIcon()
       {
           // Create a simple 16x16 filled circle as the tray icon programmatically.
           // No .ico file required — UseWindowsForms=true makes System.Drawing available.
           var bmp = new System.Drawing.Bitmap(16, 16);
           using (var g = System.Drawing.Graphics.FromImage(bmp))
           {
               g.SmoothingMode = System.Drawing.Drawing2D.SmoothingMode.AntiAlias;
               g.Clear(System.Drawing.Color.Transparent);
               g.FillEllipse(System.Drawing.Brushes.White, 1, 1, 14, 14);
           }
           var icon = System.Drawing.Icon.FromHandle(bmp.GetHicon());

           var menu = new System.Windows.Forms.ContextMenuStrip();
           var resetItem = new System.Windows.Forms.ToolStripMenuItem("Reset to Defaults");
           var quitItem  = new System.Windows.Forms.ToolStripMenuItem("Quit");

           resetItem.Click += (_, _) => Dispatcher.Invoke(ResetToDefaults);
           quitItem.Click  += (_, _) => Dispatcher.Invoke(() => Application.Current.Shutdown());

           menu.Items.Add(resetItem);
           menu.Items.Add(quitItem);

           _trayIcon = new System.Windows.Forms.NotifyIcon
           {
               Icon        = icon,
               Text        = "FuzzyClock",
               ContextMenuStrip = menu,
               Visible     = true
           };
       }
       ```

    3. In `ContentRendered` lambda (the `ContentRendered += (_, _) => { ... }` block), add a call to `InitTrayIcon()` at the end of the lambda, after `ApplyTheme()` and before the `MouseEnter`/`MouseLeave` wiring lines:
       ```csharp
       InitTrayIcon();
       ```

    4. Add a `Closed` event handler at the end of the constructor (after the `ContentRendered +=` block, before the closing `}`):
       ```csharp
       this.Closed += (_, _) =>
       {
           _trayIcon?.Dispose();
       };
       ```

    Notes:
    - Do NOT modify `OnClosing` — that saves settings and disposes StatsService; this is a separate `Closed` event for tray cleanup.
    - `Dispatcher.Invoke` is needed in the WinForms ToolStripMenuItem Click handlers because those fire on the WinForms UI thread, not the WPF Dispatcher thread; `Application.Current.Shutdown()` and `ResetToDefaults()` touch WPF elements.
    - The `using Application = System.Windows.Application;` alias at the top of the file already resolves `Application.Current.Shutdown()` correctly.
    - The programmatic bitmap approach avoids requiring any .ico asset file — confirmed no .ico exists in the project.

    Add a private method `ResetToDefaults()` in the class (after `InitTrayIcon()`, before `UpdateDialDisplay()`):

    ```csharp
    private void ResetToDefaults()
    {
        // Reset accent color to White (same as PresetWhite constant = #FFFFFFFF)
        SetAccentColor(PresetWhite);

        // Reset opacity to 100%
        SetOpacity(1.0);

        // Update opacity submenu checkmarks (ContextMenu_Opened syncs them on next open,
        // but _windowOpacity is already updated by SetOpacity above — no extra sync needed)

        // Center on primary screen
        // ActualWidth/ActualHeight are valid at runtime (ContentRendered has already fired)
        Left = (SystemParameters.PrimaryScreenWidth  - ActualWidth)  / 2;
        Top  = (SystemParameters.PrimaryScreenHeight - ActualHeight) / 2;
        _hasUserPosition = true;   // treat centered position as user-set to prevent phrase-change snap

        // Save the reset state immediately (SetAccentColor and SetOpacity each call SaveSettings(),
        // but we need to save the new position too — call once more with final state)
        SaveSettings();
    }
    ```

    Notes:
    - `SetAccentColor(PresetWhite)` calls `ApplyTheme()` and `SaveSettings()` internally — accent is applied visually immediately.
    - `SetOpacity(1.0)` sets `_windowOpacity` and `this.Opacity` and calls `SaveSettings()` internally.
    - The final `SaveSettings()` at the end of `ResetToDefaults()` ensures the new `Left`/`Top` center position is written to settings.json (the internal saves in SetAccentColor/SetOpacity don't have the updated position yet).
    - `SystemParameters.PrimaryScreenWidth` and `SystemParameters.PrimaryScreenHeight` are in the `System.Windows` namespace, already available in this file.
    - `_hasUserPosition = true` prevents the phrase-change timer from immediately snapping the widget back to top-right.
