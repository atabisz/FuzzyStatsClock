> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Architecture Gap Summary

The Nixie rendering controls (`NixieDigit`, `NixieClockView`) are complete and already
referenced in `MainWindow.xaml`. The architecture gaps that this phase must close are:

| Gap | Current State | Required State |
|-----|--------------|----------------|
| AppSettings persistence | `DialMode bool` only | `ClockType` enum field (Phrase/Dial/Lcd/Nixie) |
| SettingsSnapshot | `DialMode bool` only | `ClockType` enum field |
| SettingsWindow clock selector | 2-button rail: Phrase / Dial | 3-button rail: Phrase / Dial / Nixie |
| SettingsWindow event | `DialModeChanged: Action<bool>` | `ClockTypeChanged: Action<ClockType>` |
| MainWindow wiring | `DialModeChanged` handler | `ClockTypeChanged` handler |

The Nixie widget face itself (`NixieClockView`, `NixieDigit`) requires no visual changes
in this phase — the rendering contract below documents what already exists so the executor
and auditor have ground truth.

## Spacing Scale

This phase touches two surfaces: SettingsWindow Appearance tab (existing 4px-grid) and the
NixieClockView widget face (pixel-exact Canvas layout). Both follow the existing project
grid already established in Phase 56.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Intra-control padding (e.g., tube border padding inside NixieDigit Canvas) |
| sm | 8px | Compact row gaps on Appearance tab |
| md | 16px | Section header bottom margin on Appearance tab |
| lg | 24px | Reserved — not used on Appearance tab in this phase |
| xl | 32px | Reserved |
| 2xl | 48px | Reserved |
| 3xl | 64px | Reserved |

Exceptions:
- `SegmentButtonStyle` Padding is `12,4` (12px horizontal, 4px vertical) — pre-existing SettingsWindow pattern; carry forward for the Nixie button.
- NixieDigit geometry uses proportional arithmetic (`digitH * 0.62` for width, `digitH + 12` for canvas height) rather than fixed grid tokens — this is intentional and must not be changed.
- Colon dot margin: `4,0,4,6` (top dot) and `4,0,4,0` (bottom dot) — pre-existing; carry forward.

The Nixie face uses hardcoded amber-orange values derived from classic IN-18 tube emission.
These are independent of the user's accent color setting.

| Role | Value | Alpha | Usage |
|------|-------|-------|-------|
| Tube fill | #1A0800 | CC (80%) | Glass tube background rectangle fill |
| Tube stroke | #FF8C00 | 80 (50%) | Glass tube border stroke, 1.5pt |
| Wire mesh lines | #FF8C00 | 18 (9.4%) | Horizontal wire mesh strokes inside tube, 0.5pt, 7px spacing |
| Glass highlight | #FFFFFF | 14 (7.8%) | Top highlight rectangle simulating glass curvature reflection |
| Ghost cathode (base) | #FF8000 | 14 (7.8%) | All 10 non-active digit glyphs |
| Ghost cathode (distance 2) | #FF8000 | 18 (9.4%) | Digits 2 positions from active |
| Ghost cathode (distance 1) | #FF8000 | 1E (11.8%) | Digit 1 position from active |
| Active cathode | #FF8C00 | FF (100%) | Active digit glyph — full warm orange |
| Glow center | #FF8C00 | A0 (62.7%) | RadialGradient center behind active digit |
| Glow edge | Transparent | — | RadialGradient edge |
| Colon dots | #FF8C00 | A0 (62.7%) | ColonDot1, ColonDot2 RadialGradient center |

Accent reserved for: stats bars, stat labels, stat text, phrase text, date text, dial hands — all pre-existing. Nixie face is explicitly excluded from accent color application.

Destructive: #FFFF4444 — battery alert bar only (pre-existing, unchanged).

## SettingsWindow "Clock Style" Segment Control Contract

### Current state (before this phase)

```
[ Phrase ] [ Dial ]
```
- 2 buttons, `SegmentButtonStyle`, inside `#FF3A3A3A` rail
- `BtnPhrase_Click` fires `DialModeChanged?.Invoke(false)`
- `BtnDial_Click` fires `DialModeChanged?.Invoke(true)`

### Required state (after this phase)

```
[ Phrase ] [ Dial ] [ Nixie ]
```

- 3 buttons, same `SegmentButtonStyle`, same `#FF3A3A3A` rail
- No change to Phrase or Dial button content or padding
- New `BtnNixie` button: `Content="Nixie"`, same `Padding="12,4"`, same `SegmentButtonStyle`
- Event change: `DialModeChanged: Action<bool>` replaced by `ClockTypeChanged: Action<ClockType>`
  - `BtnPhrase_Click` fires `ClockTypeChanged?.Invoke(ClockType.Phrase)`
  - `BtnDial_Click` fires `ClockTypeChanged?.Invoke(ClockType.Dial)`
  - `BtnNixie_Click` fires `ClockTypeChanged?.Invoke(ClockType.Nixie)`
- `SetClockStyleButtonStates(ClockType ct)`: sets `Tag = "selected"` on the matching button, null on the others
- `PopulateControls` reads `s.ClockType` (not `s.DialMode`) to determine which button is active

### Width impact

The three-button rail with "Nixie" at `Padding="12,4"` adds approximately 57px to the rail width.
The Appearance tab StackPanel has no fixed width constraint — the rail is `HorizontalAlignment="Left"`.
The 480px window is not affected.

## AppSettings / SettingsSnapshot Migration Contract

### AppSettings.cs

Remove: `public bool DialMode { get; init; } = false;`
Add: `public ClockType ClockType { get; init; } = ClockType.Phrase;`

Add LCD and Nixie settings that are currently only stored in code-behind fields:

```
public bool   LcdUse24Hr      { get; init; } = false;
public bool   LcdShowSeconds  { get; init; } = true;
public string LcdStyle        { get; init; } = "Dark";
```

Note: `LcdSize` is derived from `FontSize` via `FontSizeToLcdSize()` and does NOT need to be persisted.

### SettingsSnapshot.cs

Remove: `public bool DialMode { get; init; }`
Add: `public ClockType ClockType { get; init; } = ClockType.Phrase;`

Add LCD fields mirroring AppSettings:
```
public bool   LcdUse24Hr     { get; init; } = false;
public bool   LcdShowSeconds { get; init; } = true;
public string LcdStyle       { get; init; } = "Dark";
public LcdSize LcdSize       { get; init; } = LcdSize.Medium;
```

### SettingsService migration

`SettingsService.Load()` must handle the old `dialMode: true` JSON gracefully.
Migration: if `dialMode` key is present in saved JSON and `clockType` key is absent,
read `dialMode` and convert: `true → ClockType.Dial`, `false → ClockType.Phrase`.

## Interaction States

### NixieClockView visibility states

| State | Trigger | Behaviour |
|-------|---------|-----------|
| Hidden | ClockType != Nixie | `Visibility = Collapsed`; internal timer stopped via `IsVisibleChanged` |
| Active | ClockType == Nixie | `Visibility = Visible`; internal 1s timer starts; `UpdateTime()` fires immediately |
| Font size change | `ApplyFontSize()` called | `NixieView.Size = FontSizeToLcdSize(size)` — NixieSizeMap applies new DigitHeight to all 4 digits |

### SettingsWindow Clock Style button states

| State | BtnPhrase.Tag | BtnDial.Tag | BtnNixie.Tag |
|-------|--------------|------------|-------------|
| Phrase active | "selected" | null | null |
| Dial active | null | "selected" | null |
| Nixie active | null | null | "selected" |

### Tray menu Clock submenu (pre-existing, no change required)

The tray already wires `_nixieClockItem` to `SetClockType(ClockType.Nixie)` and
reflects checked state. No tray changes are needed in this phase.
