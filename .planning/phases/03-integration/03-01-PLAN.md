```csharp
internal void SetInitialPhrase(string phrase)
{
    ShadowText.Text = phrase;
    PhraseText.Text = phrase;

```

4. Add UpdatePhraseIfChanged() method:
```csharp
private void UpdatePhraseIfChanged()
{
    string newPhrase = PhraseEngine.GetPhrase(DateTime.Now);
    if (newPhrase == PhraseText.Text) return;  // No change — skip layout work

    ShadowText.Text = newPhrase;
    PhraseText.Text = newPhrase;

    // Force layout pass before repositioning — ActualWidth is stale until layout runs
    // (SizeToContent=WidthAndHeight: ActualWidth reflects old phrase until layout re-measures)
    UpdateLayout();
    PositionTopRight();
}
```

5. Update the ContentRendered handler to start the timer after positioning:
```csharp
ContentRendered += (_, _) =>
{
    PositionTopRight();
    _timer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(10) };
    _timer.Tick += (_, _) => UpdatePhraseIfChanged();
    _timer.Start();
};
```

The timer is started in ContentRendered (not the constructor) to ensure:
- Layout has run and ActualWidth is valid before any repositioning
- The timer cannot fire before the UI is ready

Do NOT use System.Threading.Timer or Task.Delay — DispatcherTimer fires on the UI thread so no Dispatcher.Invoke is needed (locked pattern from research).
