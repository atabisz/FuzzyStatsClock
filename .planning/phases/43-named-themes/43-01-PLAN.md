- `System.Windows.Media.Color AccentColor`
- `double Opacity`
- `int FontSize`
- `bool DialMode`
- `bool StatsVisible`

Define `internal static class BuiltInThemes` with:
- `public static readonly IReadOnlyDictionary<string, ThemeDefinition> All` — a `Dictionary<string, ThemeDefinition>` with the 5 entries below.
- `public static ThemeDefinition? TryGet(string? name)` — returns `All.TryGetValue(name, out var def) ? def : null` guarded by `name is not null`.

The 5 entries (all AccentColor use `Color.FromArgb(0xFF, R, G, B)`):

| Key        | AccentColor      | Opacity | FontSize | DialMode | StatsVisible |
|------------|------------------|---------|----------|----------|--------------|
| "Midnight" | 0x6A, 0x7F, 0xDB | 0.85    | 32       | false    | false        |
| "Neon"     | 0x00, 0xF5, 0xD4 | 1.0     | 32       | true     | true         |
| "Ghost"    | 0xC0, 0xC8, 0xD8 | 0.35    | 28       | false    | false        |
| "Warm"     | 0xF4, 0xA2, 0x61 | 0.90    | 32       | false    | true         |
| "Terminal" | 0x39, 0xFF, 0x14 | 0.95    | 24       | true     | true         |

Font size rationale (per CONTEXT.md Claude's discretion):
- Midnight 32: atmospheric but readable
- Neon 32: standard (dial mode primary)
- Ghost 28: smaller reinforces barely-there aesthetic at 0.35 opacity
- Warm 32: friendly and comfortable
- Terminal 24: compact/dense hacker-terminal aesthetic

Stats visibility applies only to the panel-level StatsVisible toggle — NOT individual CPU/GPU/MEM/PAG/BATT row visibility (per Claude's discretion: preserves user's per-row preferences).

Add the `using System.Windows.Media;` directive at the top.
