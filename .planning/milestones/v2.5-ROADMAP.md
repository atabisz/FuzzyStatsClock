## Milestone Summary

**Key Decisions:**
- Extract only angle degrees from DialGeometry (not radian conversion or canvas positioning) — testable pure values only; canvas geometry stays in MainWindow
- Use component TimeSpan properties (Days/Hours/Minutes) in UptimeFormatter — matches existing MainWindow behavior exactly
- `net10.0-windows` + `UseWPF=true` in App.Tests — required to resolve WPF assembly references from FuzzyClock.App dependency
- `SettingsService.Validate()` extracted from `Load()` inline guards — pure static method makes validation testable without filesystem
- Pure `Clamp()` overload with explicit bounds — avoids `SystemParameters.VirtualScreen*` which requires WPF dispatcher context
- GitHub Actions default fail-fast (no `continue-on-error`) — step order alone guarantees Publish blocked when tests fail
- `dotnet test` on solution root, no `--filter` — all 73 tests gate the release, not just a subset

**Issues Resolved:**
- WPF assembly resolution in test project (plain `net10.0` fails; `net10.0-windows` + `UseWPF=true` required)
- `DataRow(null)` force-null pattern for non-nullable property tests: `string? param` + `value!` in test body

**Technical Debt Incurred:**
- Phase 30 live-push verification deferred: deliberate-failure push and clean-release regression push require a live GitHub Actions runner; structural guarantees statically verified but runtime fail-fast behavior unconfirmed
