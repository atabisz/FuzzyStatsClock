**2. Add `SetOpacity()` helper and four preset click handlers** — add after `SetShowHourNumbers()` and before `InitDialDecorations()`:

```csharp
{
    _windowOpacity = opacity;

}

private void MenuOpacity25_Click(object sender, RoutedEventArgs e)  => SetOpacity(0.25);

private void MenuOpacity100_Click(object sender, RoutedEventArgs e) => SetOpacity(1.00);
```

Do NOT call SetOpacity() from ApplySettings() — that calls SaveSettings() redundantly at startup. Direct assignment is the established pattern for all other ApplySettings() assignments.

**3. Add `Window_PreviewMouseWheel` handler** — add immediately after the four preset click handlers:

```csharp
private void Window_PreviewMouseWheel(object sender, MouseWheelEventArgs e)
{
    // e.Delta > 0: scroll up = increase opacity; e.Delta < 0: scroll down = decrease opacity
    // Math.Sign: exactly one 10% step per physical notch regardless of high-resolution wheel
    double step = Math.Sign(e.Delta) * 0.10;
    _windowOpacity = Math.Clamp(_windowOpacity + step, 0.10, 1.0);
    this.Opacity = _windowOpacity;
    SaveSettings();
    e.Handled = true;  // prevent scroll leaking to desktop or windows below overlay
}
```

Floor is 0.10 (10%) per success criterion SC-3 and RESEARCH.md. The preset menu's lowest option is 25% — these are not in conflict. Users reach sub-25% opacity only via scroll wheel.

**4. Extend `ApplySettings(AppSettings s)`** — add at the END of the existing method body (after `_showHourNumbers = s.ShowHourNumbers;`):

```csharp
_windowOpacity = s.Opacity;
this.Opacity   = s.Opacity;
```

UIElement.Opacity assignment before Show() is safe — requires no layout pass. Direct assignment (not SetOpacity()) matches the established pattern for all other ApplySettings() assignments.

**5. Extend `SaveSettings()`** — add `Opacity = _windowOpacity,` to the `new AppSettings { ... }` initializer, after `ShowHourNumbers = _showHourNumbers,`:

```csharp
Opacity = _windowOpacity,
```

Do NOT add AccentColor to SaveSettings() yet — AppSettings.AccentColor has init default "#FFFFFFFF" which System.Text.Json serializes correctly without explicit assignment. Phase 20 adds the AccentColor assignment.

**6. Extend `ContextMenu_Opened()`** — add at the END of the existing method body (after `MenuShowHourNumbers.IsChecked = _showHourNumbers;`):

Do NOT read IsChecked in any click handler — WPF toggles IsChecked before the handler fires, inverting the logic. All existing handlers follow this rule.
