  <name>Task 1: Add AccentColor and Opacity fields to AppSettings record</name>
  <files>FuzzyClock.App/AppSettings.cs</files>
  <action>
Add two new init-property fields to the AppSettings record, positioned after ShowHourNumbers:

```csharp
public string AccentColor { get; init; } = "#FFFFFFFF";  // AARRGGBB hex; default = White (matches existing Foreground="White" in XAML)
public double Opacity      { get; init; } = 1.0;          // 0.0–1.0; default = fully opaque
```

Critical: The Opacity init default MUST be 1.0 (not omitted). The C# type default for double is 0.0 — without = 1.0, a v1.9 settings.json (missing the Opacity field) would deserialize to Opacity=0.0, producing an invisible widget on upgrade. System.Text.Json uses the init default for absent JSON fields, so this is the sole protection in the normal upgrade path.

Critical: AccentColor MUST use "#FFFFFFFF" (8-digit ARGB), not "#FFFFFF" (6-digit RGB). Later phases call ColorConverter.ConvertFromString() on this value and write back the full ARGB format. The default must match that format to avoid a format change on first save.

Do NOT modify any existing fields. Do NOT add fields for ShowHourTicks/ShowMinuteDots/ShowHourNumbers to Defaults() — that is out of scope (see RESEARCH.md open question 1). The record stays an init-property record with no constructor. No attributes needed — System.Text.Json handles absent fields via init defaults natively.

  <action>
Make two changes to SettingsService.cs:

**Change 1 — Update Defaults():**
Add AccentColor and Opacity to the Defaults() factory:

```csharp
public static AppSettings Defaults() => new()
{
    Left = -1, Top = 20, FontSize = 32,
    StatsVisible = false, StatsIntervalSeconds = 3,
    CpuVisible = true, GpuVisible = true, MemVisible = true,
    PagVisible = true, DialMode = false,
    AccentColor = "#FFFFFFFF",
    Opacity = 1.0
};
```

IMPORTANT: Defaults() must be updated BEFORE the Load() guards, because the guards call Defaults().Opacity and Defaults().AccentColor. If Defaults() does not include these fields, Defaults().Opacity returns 0.0 (the init default from the record) — the guard would then reset Opacity to 0.0 instead of 1.0, which is wrong.

**Change 2 — Add two guards in Load():**
Insert the new guards immediately after the existing StatsIntervalSeconds guard, before the return statement:

```csharp
// Existing guard (unchanged):
if (loaded.StatsIntervalSeconds <= 0)
    loaded = loaded with { StatsIntervalSeconds = Defaults().StatsIntervalSeconds };

// NEW: Opacity guard — prevents invisible-widget regression on v1.9 upgrade
// (C# double type default is 0.0; "Opacity":0.0 in malformed JSON or an explicit
// zero written by a future bug would make the widget fully transparent with no
// way to recover without deleting settings.json)
if (loaded.Opacity <= 0.0)
    loaded = loaded with { Opacity = Defaults().Opacity };

// NEW: AccentColor guard — prevents NullReferenceException in ColorConverter.ConvertFromString
// (protects against "AccentColor":null or "AccentColor":"" in a manually edited settings file)
if (string.IsNullOrWhiteSpace(loaded.AccentColor))
    loaded = loaded with { AccentColor = Defaults().AccentColor };

return loaded;
```

Do NOT restructure or reformat any existing code. The with-expression pattern is already established by the StatsIntervalSeconds guard — follow it exactly.
