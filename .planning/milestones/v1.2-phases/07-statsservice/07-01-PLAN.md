**Step 3 — Create FuzzyClock.App/StatsService.cs**

Implement the complete StatsService using the skeleton from the research document. Key implementation requirements:

```
namespace: FuzzyClock.App
class: public sealed class StatsService : IDisposable
```

Fields (all private):
- `PerformanceCounter? _cpuCounter` — initialized in background thread
- `PerformanceCounter? _memCounter` — initialized in background thread
- `PerformanceCounter[] _gpuCounters = []` — populated by BuildGpuCounters()
- `bool _gpuAvailable` — set during Initialize(); controls all GPU paths
- `volatile bool _initialized` — set true at end of Initialize(); guards Refresh()

Properties (public, private set):
- `float CpuPercent { get; private set; }` — range [0, 100]
- `float GpuPercent { get; private set; } = -1f` — -1f = unavailable sentinel
- `float MemPercent { get; private set; }` — range [0, 100]

Constructor: call `Task.Run(Initialize)` only — no other logic.

Initialize() (private void, runs on background thread):
1. `_cpuCounter = new PerformanceCounter("Processor", "% Processor Time", "_Total", readOnly: true);`
2. `_cpuCounter.NextValue();` — prime (discard); rate counter always returns 0 on first call
3. `_memCounter = new PerformanceCounter("Memory", "% Committed Bytes In Use", readOnly: true);` — no priming needed (point-in-time counter)
4. `_gpuAvailable = PerformanceCounterCategory.Exists("GPU Engine");`
5. If `_gpuAvailable`: call `BuildGpuCounters()`, prime each GPU counter with `c.NextValue()`
6. `GpuPercent = _gpuAvailable ? 0f : -1f;`
7. `_initialized = true;` — MUST be last statement

Refresh() (public void, will be called from timer tick in Phase 8):
1. `if (!_initialized) return;` — safe no-op during startup
2. `CpuPercent = _cpuCounter?.NextValue() ?? 0f;`
3. `MemPercent = _memCounter?.NextValue() ?? 0f;`
4. If `!_gpuAvailable`: return early
5. Try: `GpuPercent = _gpuCounters.Length > 0 ? Math.Min(_gpuCounters.Sum(c => c.NextValue()), 100f) : 0f;`
6. Catch `InvalidOperationException`: dispose current GPU counters, call `BuildGpuCounters()` again, re-prime all, set `GpuPercent = 0f`

BuildGpuCounters() (private PerformanceCounter[]):
- Try: create `PerformanceCounterCategory("GPU Engine")`, call `GetInstanceNames()`, filter by `.Contains("engtype_3D", StringComparison.OrdinalIgnoreCase)`, select new `PerformanceCounter("GPU Engine", [counter-name-from-typeperf], n, readOnly: true)` for each, return as array
- Catch all: set `_gpuAvailable = false`, return `[]`

DisposeGpuCounters() (private void): foreach dispose, then `_gpuCounters = []`

Dispose() (public void, implements IDisposable):
- `_cpuCounter?.Dispose()`
- `_memCounter?.Dispose()`
- `DisposeGpuCounters()`

**Step 1 — Add temporary verification wiring in App.xaml.cs**

1. Creates a `StatsService` instance
2. Waits 2 seconds for async init to complete (`await Task.Delay(2000)` — use `async void OnStartup`)

4. Calls `s.Dispose()` after the loop

Use `System.Diagnostics` namespace (already available since it's the same assembly as PerformanceCounter).

Important: wrap the entire block in `#if DEBUG` / `#endif` to keep Release builds clean. The block runs concurrently with the normal app startup — it MUST NOT block or replace existing startup logic.

Example structure:
```csharp
#if DEBUG
_ = Task.Run(async () =>
{
    var s = new StatsService();
    await Task.Delay(2000);
    for (int i = 0; i < 5; i++)
    {
        s.Refresh();
        System.Diagnostics.Debug.WriteLine(
            $"[StatsService] CPU={s.CpuPercent:F0}% GPU={s.GpuPercent:F0}% MEM={s.MemPercent:F0}%");
        await Task.Delay(1000);
    }
    s.Dispose();
});
#endif
```
