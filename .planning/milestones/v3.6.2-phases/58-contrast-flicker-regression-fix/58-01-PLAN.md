<objective>
Fix the contrast flicker regression by adding the missing `SHELLDLL_DefView` Windows shell class to the exclusion list in `HasAppWindowBeneath`.

Purpose: The v3.6.1 guard skips BitBlt sampling over empty desktop but omits `SHELLDLL_DefView` (the desktop icon host window), causing the guard to return `true` on machines where desktop icons are visible. This re-triggers the feedback loop oscillation.

Output: Single-line fix in `ContrastRefreshController.cs`, verified by build + full test suite + human verification of flicker-free behavior.
</objective>

```csharp
private static bool HasAppWindowBeneath(IntPtr widgetHwnd, RECT widgetRect)
{
    var className = new StringBuilder(256);
    IntPtr candidate = GetWindow(widgetHwnd, GW_HWNDNEXT);
    while (candidate != IntPtr.Zero)
    {
        if (IsWindowVisible(candidate) &&
            GetWindowRect(candidate, out RECT r) &&
            Overlaps(widgetRect, r))
        {
            GetClassName(candidate, className, 256);
            string cls = className.ToString();
            if (cls != "Progman" && cls != "WorkerW" && cls != "SysListView32")
                return true;
            className.Clear();
        }
        candidate = GetWindow(candidate, GW_HWNDNEXT);
    }
    return false;
}
```
