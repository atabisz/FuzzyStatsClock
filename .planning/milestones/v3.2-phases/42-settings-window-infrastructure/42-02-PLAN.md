Create `FuzzyClock.App/SettingsWindow.xaml.cs`. This is the code-behind for the SettingsWindow.

**Architecture rules (CRITICAL):**
- SettingsWindow NEVER writes to `AppSettings` directly
- SettingsWindow NEVER holds a reference to `MainWindow`
- Every control change fires an event immediately (live-apply)
- Use `_suppressEvents = true` during `PopulateControls()` to prevent spurious events during initialization
- Subscribe event handlers AFTER PopulateControls() returns (or check `_suppressEvents` at top of each handler)

**Events to expose (one per setting change):**
```csharp
public event Action<System.Windows.Media.Color>? AccentColorChanged;
public event Action<double>? OpacityChanged;
public event Action<int>? FontSizeChanged;
public event Action<bool>? DialModeChanged;
public event Action<string>? PhraseStyleChanged;
public event Action<bool>? StatsVisibleChanged;
public event Action<bool>? CpuVisibleChanged;
public event Action<bool>? GpuVisibleChanged;
public event Action<bool>? MemVisibleChanged;
public event Action<bool>? PagVisibleChanged;
public event Action<bool>? BatteryVisibleChanged;
public event Action<bool>? UptimeVisibleChanged;
public event Action<int>? StatsIntervalChanged;
public event Action<double>? ProcessThresholdChanged;
public event Action<bool>? ShowDateChanged;
public event Action<string>? DateFormatChanged;
public event Action<bool>? GhostModeChanged;
public event Action<bool>? AutoContrastChanged;
public event Action<bool>? AutoLaunchChanged;
```

**Constructor:**
```csharp
public SettingsWindow(SettingsSnapshot snapshot)
{
    InitializeComponent();
    _suppressEvents = true;
    PopulateControls(snapshot);
    _suppressEvents = false;
}
```

**Position memory (within-session):** Declare `private static double _savedLeft = double.NaN;` and `_savedTop = double.NaN` as static fields on SettingsWindow. In the constructor, after InitializeComponent(), if `!double.IsNaN(_savedLeft)` then set `WindowStartupLocation = WindowStartupLocation.Manual; Left = _savedLeft; Top = _savedTop;`. In the `Closing` event handler, save `_savedLeft = Left; _savedTop = Top;`.

**PopulateControls(SettingsSnapshot s):** Set each control's value from the snapshot:
- `OpacitySlider.Value = s.Opacity;`
- `OpacityLabel.Text = $"{(int)(s.Opacity * 100)}%";`
- Call `SetFontSizeButtonStates(s.FontSize)` and `SetClockStyleButtonStates(s.DialMode)`
- Set `CmbPhraseStyle.SelectedItem` by finding the item whose Content == s.PhraseStyle (or SelectedIndex=0 for "Classic")
- Set all CheckBox IsChecked values from snapshot booleans
- Set `CmbStatsInterval.SelectedIndex` based on s.StatsIntervalSeconds (0=1s, 1=3s, 2=10s)
- Set RadioButton IsChecked for RbThresh2/5/10 based on s.ProcessCountThreshold
- Set `CmbDateFormat.SelectedIndex` based on s.DateFormat ("Short"=0, "Long"=1, "Numeric"=2, "ISO"=3)

**Toggle button state helpers:**
```csharp
private void SetFontSizeButtonStates(int size)
{
    BtnFontS.FontWeight  = size == 16 ? FontWeights.Bold : FontWeights.Normal;
    BtnFontM.FontWeight  = size == 24 ? FontWeights.Bold : FontWeights.Normal;
    BtnFontL.FontWeight  = size == 32 ? FontWeights.Bold : FontWeights.Normal;
    BtnFontXL.FontWeight = size == 40 ? FontWeights.Bold : FontWeights.Normal;
}

private void SetClockStyleButtonStates(bool dialMode)
{
    BtnPhrase.FontWeight = !dialMode ? FontWeights.Bold : FontWeights.Normal;
    BtnDial.FontWeight   =  dialMode ? FontWeights.Bold : FontWeights.Normal;
}
```

**Event handlers — pattern for each (check `_suppressEvents` first):**
```csharp
private void OpacitySlider_ValueChanged(object sender, RoutedPropertyChangedEventArgs<double> e)
{
    if (_suppressEvents) return;
    double v = Math.Round(e.NewValue, 2);
    OpacityLabel.Text = $"{(int)(v * 100)}%";
    OpacityChanged?.Invoke(v);
}
```

Swatch click handlers: Each `SwatchX_MouseLeftButtonDown` reads the Border's Background as SolidColorBrush, invokes `AccentColorChanged?.Invoke(color)`.

Custom color button: `CustomColor_Click` opens the existing WinForms ColorDialog using `Win32Window` adapter (already in codebase, same pattern as MainWindow.OpenCustomColorDialog). On OK, invoke `AccentColorChanged?.Invoke(color)`.

Font size buttons: `BtnFontS_Click` etc. call `SetFontSizeButtonStates(16)` then `FontSizeChanged?.Invoke(16)`.

Clock style buttons: `BtnPhrase_Click` calls `SetClockStyleButtonStates(false)` then `DialModeChanged?.Invoke(false)`. `BtnDial_Click` calls `SetClockStyleButtonStates(true)` then `DialModeChanged?.Invoke(true)`.

Phrase style combo: `CmbPhraseStyle_SelectionChanged` invokes `PhraseStyleChanged?.Invoke((string)((ComboBoxItem)CmbPhraseStyle.SelectedItem).Content)`.

Checkbox Checked/Unchecked handlers: Each fires the corresponding boolean event. Example: `ChkGhostMode_Changed` fires `GhostModeChanged?.Invoke(ChkGhostMode.IsChecked == true)`. Wire both `Checked` and `Unchecked` events to the same handler.

Stats interval combo: `CmbStatsInterval_SelectionChanged` maps SelectedIndex to 1/3/10 seconds: `int[] intervals = [1, 3, 10]; StatsIntervalChanged?.Invoke(intervals[CmbStatsInterval.SelectedIndex]);`

Process threshold radio buttons: Each `RbThreshX_Checked` fires `ProcessThresholdChanged?.Invoke(X.0)`.

Date format combo: `CmbDateFormat_SelectionChanged` maps SelectedIndex to "Short"/"Long"/"Numeric"/"ISO".

Wire all XAML event handler names in the XAML file (e.g. `ValueChanged="OpacitySlider_ValueChanged"`).
