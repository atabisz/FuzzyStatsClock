## Tech Debt

### Phase 51: App Integration

**1. `SaveSettings()` missing `LcdSize`** (Moderate)
- File: `FuzzyClock.App/MainWindow.xaml.cs` ~line 513
- Issue: `_settings with { ... }` sets `LcdTheme`, `LcdUse24Hr`, `LcdShowSeconds` but omits `LcdSize`
- Impact: `settings.json` always stores `LcdSize: Medium`; value is meaningless
- Workaround: `LcdView.Size` is set correctly at runtime via `FontSizeToLcdSize(_currentFontSize)` from the persisted `FontSize` field
- Fix: Add `LcdSize = FontSizeToLcdSize(_currentFontSize),` to the record update

**2. `SettingsSnapshot` missing `LcdSize`** (Low)
- File: `FuzzyClock.App/SettingsSnapshot.cs`
- Issue: `SettingsSnapshot` has `LcdTheme`, `LcdUse24Hr`, `LcdShowSeconds` but no `LcdSize`
- Impact: No runtime defect (no SettingsWindow UI for LcdSize exists); consistency gap for future work
- Fix: Add `LcdSize LcdSize { get; init; }` and populate from `AppSettings.LcdSize` in snapshot creation

### Phase 52: Tests + README

**3. README theme table missing Ghost color column** (Minor)
- File: `README.md` lines 38–44
- Issue: Theme table has "Lit Color" and "Background" columns but not "Ghost" (the dimmed inactive segment color)
- Impact: Documentation incompleteness; no code defect
- Fix: Add a "Ghost color" column to the README theme table
