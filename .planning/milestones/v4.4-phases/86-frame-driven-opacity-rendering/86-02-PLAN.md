<objective>
Refactor `MainWindow` to drive the visible fade through a per-frame lerp pump on `CompositionTarget.Rendering`, fully decoupled from the 33 ms sampling cadence. The pump glides `_currentRatio` toward `_targetRatio` (set by Phase 85's `ProximityChanged` callback) using the pure `GhostModeController.LerpRatio` helper added in Plan 01, snapping at terminal values per D-03. Subscription is owned by an `EnabledChanged` handler so the per-frame loop has zero overhead while ghost mode is disabled (FADE-04). Every existing `MainWindow` interaction guard — `_isDragging`, settings-window-open, `_menuOpen` (RMB-04 menu pin), and the mouse-wheel `SetOpacity` direct write — is preserved verbatim (SEM-04).

Purpose: This is the behaviorally-significant edit of Phase 86 — it makes the visible fade actually frame-driven (FADE-01), splits target vs current state (FADE-02), preserves crisp activation/restore via the snap (FADE-03), zeroes overhead when disabled (FADE-04), and keeps every existing guard byte-for-byte equivalent (SEM-04).

Output: `MainWindow.xaml.cs` has `_currentRatio` (renamed from `_proximityRatio`) and a sibling `_targetRatio`, an `OnRenderingTick` handler running per render frame, an `OnGhostEnabledChanged` handler attaching/detaching the pump, a `LerpAlpha = 15.0` const, a `_renderPumpAttached` guard, deltaSeconds tracking with first-frame baseline + clamp, the moved guard chain inside the render pump, the renamed/repointed `Restored` and `SetOpacity` paths, and an explicit detach in `this.Closed`. All 129 + 449 existing tests still pass; `GhostModeController.cs` is unchanged in this plan (Plan 01 owns it).
</objective>
