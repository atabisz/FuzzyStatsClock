## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-86-01 | Tampering | EnabledChanged double-fire on idempotent write | mitigate | Setter change-detect (D-04) — if `_isEnabled == value` return early; settings.json restore that writes the existing value at startup raises zero events. | T-86-02 | Tampering | Subscriber re-entrancy via EnabledChanged setter recursion | mitigate | Setter writes `_isEnabled = value` BEFORE invoking `EnabledChanged?.Invoke(value)`; if a subscriber writes `IsEnabled = !value` synchronously, the second setter call sees the just-written field and either returns (if equal — impossible here since negated) or recurses with the change-detect guard preventing infinite loop. |

| T-86-04 | Information disclosure | None — pure helper, additive event | accept | No new I/O, no new persisted state, no log emission. |
