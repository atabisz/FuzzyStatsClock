<objective>
Add a configurable process count threshold (2%/5%/10% CPU) to the tray Stats submenu so the user can control which processes are counted in the `{N}p` uptime line display.

Purpose: The `{N}p` count currently hardcodes `pct >= 5.0`; this phase exposes that constant as a user-persisted setting selectable from the tray.
Output: Three mutually-exclusive checkable items in the tray Stats submenu; threshold persisted to settings.json; `UpdateUptimeDisplay()` uses the persisted value; Reset to Defaults restores 5%.
</objective>
