Add/modify these steps in order after checkout and setup:

**Step: Extract version from tag** (new step, id: `version`)
```yaml
- name: Extract version from tag
  id: version
  shell: bash
  run: |
    TAG="${GITHUB_REF#refs/tags/v}"
    IFS='.' read -ra PARTS <<< "$TAG"
    MAJOR="${PARTS[0]:-0}"
    MINOR="${PARTS[1]:-0}"
    PATCH="${PARTS[2]:-0}"
    echo "version=$MAJOR.$MINOR.$PATCH" >> "$GITHUB_OUTPUT"
```

**Step: Restore** (keep existing)
```yaml
- name: Restore
  run: dotnet restore -r win-x64 -p:PublishReadyToRun=true
```

**Step: Test** (keep existing)
```yaml
- name: Test
  run: dotnet test --no-restore --configuration Release
```

**Step: Publish** (modify — add version properties)
```yaml
- name: Publish
  run: >
    dotnet publish FuzzyClock.App
    -r win-x64
    -c Release
    --no-restore
    --self-contained true
    -p:PublishSingleFile=true
    -p:PublishReadyToRun=true
    -p:IncludeNativeLibrariesForSelfExtract=true
    -p:Version=${{ steps.version.outputs.version }}
    -p:AssemblyVersion=${{ steps.version.outputs.version }}.0
    -p:FileVersion=${{ steps.version.outputs.version }}.0
    -o publish/
```

**Step: Rename EXE artifact** (new)
```yaml
- name: Rename EXE artifact
  shell: bash
  run: mv publish/FuzzyClock.exe "publish/FuzzyClock-${{ steps.version.outputs.version }}.exe"
```

**Step: Compile installer** (new — uses `cmd` shell, full ISCC path)
```yaml
- name: Compile installer
  shell: cmd
  run: >
    "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
    /DAppVersion=${{ steps.version.outputs.version }}
    /DSourceDir=publish
    FuzzyClock.iss
```
Note: ISCC reads from the `SourceDir` preprocessor variable which points to `publish/` where the renamed EXE lives. However, the .iss `[Files]` section references `{#SourceDir}\FuzzyClock.exe` — so the EXE in publish/ must still be named `FuzzyClock.exe` at ISCC compile time. **Important:** Move the "Rename EXE artifact" step to AFTER the "Compile installer" step so ISCC can find `publish/FuzzyClock.exe`. The rename happens after ISCC is done.

Corrected step order:
1. Extract version
2. Restore
3. Test
4. Publish (outputs `publish/FuzzyClock.exe`)
5. Compile installer (reads `publish/FuzzyClock.exe`, outputs `installer/FuzzyClockSetup-X.Y.Z.exe`)
6. Rename EXE (`publish/FuzzyClock.exe` -> `publish/FuzzyClock-X.Y.Z.exe`)
7. Generate checksums
8. Create draft GitHub Release

**Step: Generate checksums** (new)
```yaml
- name: Generate checksums
  shell: pwsh
  run: |
    $ver = "${{ steps.version.outputs.version }}"
    $exe = "publish/FuzzyClock-$ver.exe"
    $setup = "installer/FuzzyClockSetup-$ver.exe"
    $h1 = (Get-FileHash $exe -Algorithm SHA256).Hash
    $h2 = (Get-FileHash $setup -Algorithm SHA256).Hash
    "SHA256 (FuzzyClock-$ver.exe) = $h1" | Out-File -FilePath checksums.txt -Encoding utf8
    "SHA256 (FuzzyClockSetup-$ver.exe) = $h2" | Out-File -FilePath checksums.txt -Append -Encoding utf8
```
