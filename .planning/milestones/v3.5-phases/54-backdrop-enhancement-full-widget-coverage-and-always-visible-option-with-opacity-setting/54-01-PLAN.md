<objective>
Add full-widget backdrop coverage, always-visible option, and configurable opacity.

Purpose: The existing hover backdrop only covers the phrase/dial row (ContentBorder). This plan extends backdrop coverage to the entire widget via a new BackdropBorder, adds an always-visible option so users can keep the backdrop permanently, and makes the backdrop opacity user-configurable via a slider in the Settings window Appearance tab.

Output: BackdropBorder in MainWindow.xaml, two new AppSettings properties, code-behind logic at all backdrop sites, and a Backdrop section in SettingsWindow.
</objective>
