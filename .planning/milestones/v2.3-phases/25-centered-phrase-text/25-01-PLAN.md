  <action>
Edit `FuzzyClock.App/MainWindow.xaml`. Locate the inner Grid inside ContentBorder (the Grid that contains ShadowText, PhraseText, and DialCanvas). Add two attributes to each of the two named TextBlocks:

**ShadowText** — currently:
```xml
<TextBlock x:Name="ShadowText"
           Text=""
           FontFamily="Segoe UI Light"
           FontSize="32"
           Foreground="#BB000000"
           IsHitTestVisible="False">
```
Change to:
```xml
<TextBlock x:Name="ShadowText"
           Text=""
           FontFamily="Segoe UI Light"
           FontSize="32"
           Foreground="#BB000000"
           IsHitTestVisible="False"
           HorizontalAlignment="Stretch"
           TextAlignment="Center">
```

**PhraseText** — currently:
```xml
<TextBlock x:Name="PhraseText"
           Text=""
           FontFamily="Segoe UI Light"
           FontSize="32"
           Foreground="White" />
```
Change to:
```xml
<TextBlock x:Name="PhraseText"
           Text=""
           FontFamily="Segoe UI Light"
           FontSize="32"
           Foreground="White"
           HorizontalAlignment="Stretch"
           TextAlignment="Center" />
```

DO NOT touch DialCanvas, StatsPanel, UptimeText, ContentBorder, or any code-behind (.cs) files.

Why TextAlignment="Center" and not HorizontalAlignment="Center": HorizontalAlignment="Center" collapses the TextBlock layout width to content size and centers the element within the parent -- the glyphs would still be left-aligned within a content-sized box. TextAlignment="Center" centers the glyphs within the element's full layout width. Grid children already default to HorizontalAlignment="Stretch" (filling available width), so adding TextAlignment="Center" centers the glyphs within that full span. Both TextBlocks must have identical alignment so the shadow TranslateTransform X="2" Y="2" offset remains visually correct at all phrase lengths and font sizes.
