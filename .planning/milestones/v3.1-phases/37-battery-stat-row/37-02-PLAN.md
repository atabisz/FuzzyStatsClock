- Lightning bolt appears whenever AC power is connected (IsPluggedIn == true)
- No lightning bolt on battery-only power
- Uniform accent color (same as other rows -- no special low-battery color)
- Hidden by default on no-battery machines; but BatteryVisible AppSettings default is true
- Tray toggle always present regardless of battery presence
- No-battery row shows empty bar (0% fill) + "N/A" text
- N/A behavior: BatteryPercent == -1f from StatsService
- Label text: "BATT" (consistent with CPU/GPU/MEM/PAG)

The lightning bolt is the Unicode character U+26A1 written as the literal character in source: plug the character directly into the string, do not use an escape sequence.
