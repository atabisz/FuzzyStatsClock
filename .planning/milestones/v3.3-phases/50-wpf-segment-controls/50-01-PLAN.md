namespace FuzzyClock.Core;
public static class SevenSegmentEncoder
{
    // Returns 7-bit mask (bits 0-6 = segments a-g).
    // 0x80 = colon sentinel (special-case in renderer — NOT a segment bit).
    // 0x00 = space (all segments off).
    // Throws ArgumentException for unsupported characters.
    public static byte Encode(char c);
}
```

Segment bit layout (bits 0–6):
- bit 0 = a (top horiz)
- bit 1 = b (top-right vert)
- bit 2 = c (bottom-right vert)
- bit 3 = d (bottom horiz)
- bit 4 = e (bottom-left vert)
- bit 5 = f (top-left vert)
- bit 6 = g (middle horiz)

namespace FuzzyClock.App;

internal static class LcdTimeFormatHelper
{
    public static string FormatTime(System.DateTime now, bool use24Hr, bool showSeconds)
    {
        if (use24Hr)
        {
            return showSeconds
                ? $"{now.Hour:D2}:{now.Minute:D2}:{now.Second:D2}"
                : $"{now.Hour:D2}:{now.Minute:D2}";
        }
        else
        {
            int h = now.Hour % 12;
            if (h == 0) h = 12;
            string hourStr = h < 10 ? $" {h}" : $"{h}";
            return showSeconds
                ? $"{hourStr}:{now.Minute:D2}:{now.Second:D2}"
                : $"{hourStr}:{now.Minute:D2}";
        }
    }
}
```

**SevenSegmentDigit.xaml.cs** — full implementation in namespace `FuzzyClock.App.Controls`:

**Dependency properties** (three, all route to OnVisualPropertyChanged → UpdateSegments()):
- `Character` (char, default `' '`)
- `Theme` (LcdTheme, default `LcdTheme.Green`)
- `SegmentHeight` (double, default `48.0`) — routes to OnSegmentHeightChanged → RebuildGeometry() then UpdateSegments()

**Fields:**
- `Polygon[] _segments` — 7 Polygon instances (indices 0–6 = segments a–g), created in RebuildGeometry()
- `Rectangle _dot1, _dot2` — two rectangular colon dots, created in RebuildGeometry()
- `Rectangle _backgroundRect` — background fill, created in RebuildGeometry()
- `SolidColorBrush _litBrush, _ghostBrush, _bgBrush` — cached, recreated only when Theme changes

**Constructor:** Call RebuildGeometry(), then UpdateSegments().

**RebuildGeometry():**
- Clear RootCanvas.Children
- Compute geometry constants from SegmentHeight (h):
  - `t = h * 0.13` (thickness)
  - `gap = h * 0.05` (inter-segment gap, edge-to-edge)
  - `pad = h * 0.05` (internal padding)
  - `ch = t * 0.5` (chamfer size)
  - `bw = h * 0.6 - 2*pad` (horizontal bar width, geometry span)
  - `vhalf = (h - 3*t - 4*gap) / 2` (half-height of vertical segments)
  - `digitW = h * 0.6` (total canvas width for digit character)
  - `colonW = digitW * 0.30` (canvas width for colon character)
  - `canvasH = h + 2*pad`
- Detect if character is colon slot: use `Character == ':'` to determine canvas width at this point, OR always build both digit-width geometry and resize canvas in UpdateSegments(). Simplest: always build at digitW; in UpdateSegments() adjust Canvas.Width based on Character.
- Create _backgroundRect (Width=digitW, Height=canvasH, Canvas.Left=0, Canvas.Top=0), add to Canvas
- Create 7 Polygon instances with PointCollections computed from segment positions. Use helper methods HorizontalSegment(x, y, bw, t) and VerticalSegment(x, y, vhalf, t).

Segment layout (all coords relative to Canvas top-left, x/y are the segment origin):

| Index | Seg | Type | x | y |
|-------|-----|------|---|---|
| 0 | a (top horiz) | H | pad | pad |
| 1 | b (top-right vert) | V | pad + bw - t + gap | pad + t + gap |
| 2 | c (bot-right vert) | V | pad + bw - t + gap | pad + t + gap + vhalf + t + 2*gap |
| 3 | d (bottom horiz) | H | pad | pad + 2*t + 2*vhalf + 4*gap |
| 4 | e (bot-left vert) | V | pad + gap | pad + t + gap + vhalf + t + 2*gap |
| 5 | f (top-left vert) | V | pad + gap | pad + t + gap |
| 6 | g (middle horiz) | H | pad | pad + t + vhalf + 2*gap |

Add all 7 Polygons to RootCanvas.Children.

Create _dot1 and _dot2 as Rectangle with Width=t, Height=t, placed at:
- _dot1: Canvas.Left = (digitW - t) / 2, Canvas.Top = canvasH / 3 - t / 2
- _dot2: Canvas.Left = (digitW - t) / 2, Canvas.Top = 2 * canvasH / 3 - t / 2

Add dots to RootCanvas.Children.

Set RootCanvas.Width = digitW, RootCanvas.Height = canvasH.
Also set this.Width = digitW, this.Height = canvasH (so parent StackPanel measures correctly).

**HorizontalSegment(x, y, barWidth, thickness):** Returns PointCollection with 6 points (chamfered ends, elongated hexagon):
```
(x+ch, y), (x+barWidth-ch, y), (x+barWidth, y+ch),
(x+barWidth-ch, y+thickness), (x+ch, y+thickness), (x, y+ch)
```

**VerticalSegment(x, y, barHeight, thickness):** Returns PointCollection with 6 points:
```
(x+ch, y), (x+thickness, y+ch), (x+thickness, y+barHeight-ch),
(x+ch, y+barHeight), (x, y+barHeight-ch), (x, y+ch)
```
where ch = thickness * 0.5.

**UpdateSegments():**
- Rebuild lit/ghost/bg brushes if Theme changed (cache as fields, compare to last theme)
- Set _backgroundRect.Fill = _bgBrush
- If Character == ':':
  - Set all 7 segment Polygons Visibility=Hidden
  - Set _dot1.Fill = _litBrush, _dot2.Fill = _litBrush
  - Set RootCanvas.Width = colonW (= h * 0.6 * 0.30), this.Width = colonW
  - Return
- Else (digit or space):
  - Set all 7 segment Polygons Visibility=Visible
  - Set _dot1.Fill = _ghostBrush, _dot2.Fill = _ghostBrush
  - Set RootCanvas.Width = digitW, this.Width = digitW
  - byte mask = SevenSegmentEncoder.Encode(Character) — note: space returns 0x00 (all off), digits return bit masks
  - For i = 0..6: _segments[i].Fill = ((mask >> i) & 1) == 1 ? _litBrush : _ghostBrush

Important notes:
- Ghost segments are VISIBLE at ghost color (never Visibility=Hidden for segment slots)
- Only colon slot hides the 7-segment Polygons (they're replaced by dots)
- Background is fully opaque (no transparency) — per locked decision
- Do NOT use Opacity property reduction for ghost effect — use fill color swap only
- Brush caching: store `_lastTheme` field; recreate brushes only when `Theme != _lastTheme`
- The colon width adjustment (RootCanvas.Width = colonW) must also update _backgroundRect.Width
