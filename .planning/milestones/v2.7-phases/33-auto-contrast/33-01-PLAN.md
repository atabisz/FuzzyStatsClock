  <behavior>
    ## ContrastState enum (in ContrastService.cs or same file)

    ```csharp
    public enum ContrastState { Normal, Override }
    ```

    - Normal: accent color currently meets threshold (or feature is disabled)
    - Override: accent was replaced with adjusted/fallback color

    ## ContrastService (internal static class)

    ### RelativeLuminance(Color c) -> double

    WCAG 2.1 formula. Linearize each channel: if sRGB/255 <= 0.04045 → divide by 12.92, else → ((sRGB/255 + 0.055)/1.055)^2.4.
    Then: L = 0.2126*R + 0.7152*G + 0.0722*B.
    Alpha channel is ignored (treat as fully opaque).

    ### ContrastRatio(Color a, Color b) -> double

    Standard WCAG ratio: (lighter + 0.05) / (darker + 0.05), where lighter/darker are the higher/lower relative luminances.
    Range: 1.0 (identical) to 21.0 (black vs white).

    ### ComputeDisplayColor(Color background, Color accent, ContrastState currentState) -> (Color displayColor, ContrastState newState)

    Hysteresis thresholds (from CONTEXT.md):
    - Enter override when ratio < 4.5
    - Exit override (restore accent) when ratio > 5.5

    Logic:
    1. ratio = ContrastRatio(background, accent)
    2. If ratio >= 5.5 AND currentState == Override → newState = Normal, return (accent, Normal)
    3. If ratio >= 4.5 AND currentState == Normal → return (accent, Normal)  [already fine]
    4. If ratio < 4.5 OR (currentState == Override AND ratio <= 5.5):
       a. Try AdjustAccent(background, accent) → adjustedColor
       b. If ContrastRatio(background, adjustedColor) >= 4.5 → return (adjustedColor, Override)
       c. Else: fallback = black or white (whichever has higher contrast vs background) → return (fallback, Override)

    NOTE: When the caller passes `currentState = Override` and ratio is between 4.5–5.5 (hysteresis band), we stay in Override even if adjusted color passes — the accent itself still fails 5.5 threshold.

    ### AdjustAccent(Color background, Color accent) -> Color (internal/private helper)

    Strategy (per CONTEXT.md):
    - Darken accent if background luminance > 0.5 (light background)
    - Lighten accent if background luminance <= 0.5 (dark background)
    - Step in HSL lightness by 5 units per iteration, up to ±40 units max
    - Return first adjusted color that achieves >= 4.5:1 contrast
    - Return original accent if no adjustment within ±40 reaches threshold (caller then falls back to black/white)

    HSL conversion helpers:
    - ColorToHsl(Color) -> (double h, double s, double l) — l is 0–100 range
    - HslToColor(double h, double s, double l, byte a) -> Color

    Cases: input → expected output
    - Pure white background, pure white accent → AdjustAccent darkens accent → ContrastRatio of result >= 4.5
    - Pure black background, pure black accent → AdjustAccent lightens accent → ContrastRatio of result >= 4.5
    - Mid-gray background (#808080), mid-saturation orange accent (e.g. #FF8800) → adjusted fails → caller returns black or white
    - White background, black accent → ratio ~21.0 → Normal state, no adjustment needed

    ```csharp
    public readonly record struct RgbColor(byte R, byte G, byte B);

    public enum ContrastState { Normal, Override }

    internal static class ContrastService
    {
        // RelativeLuminance, ContrastRatio, ComputeDisplayColor, AdjustAccent,
        // ColorToHsl, HslToColor
    }
    ```

    RelativeLuminance implementation:
    - For each channel c in {R,G,B}: linear = (c/255.0 <= 0.04045) ? (c/255.0)/12.92 : Math.Pow((c/255.0 + 0.055)/1.055, 2.4)
    - Return 0.2126*linR + 0.7152*linG + 0.0722*linB

    ContrastRatio(a, b):
    - la = RelativeLuminance(a), lb = RelativeLuminance(b)
    - lighter = Math.Max(la, lb), darker = Math.Min(la, lb)
    - return (lighter + 0.05) / (darker + 0.05)

    ComputeDisplayColor(RgbColor background, RgbColor accent, ContrastState currentState):
    - ratio = ContrastRatio(background, accent)
    - if (ratio > 5.5 && currentState == ContrastState.Override) return (accent, Normal)
    - if (ratio >= 4.5 && currentState == ContrastState.Normal) return (accent, Normal)
    - // Need override: try adjustment
    - adjusted = AdjustAccent(background, accent)
    - if (ContrastRatio(background, adjusted) >= 4.5) return (adjusted, Override)
    - // Fallback: black vs white
    - var black = new RgbColor(0, 0, 0); var white = new RgbColor(255, 255, 255);
    - fallback = (ContrastRatio(background, white) >= ContrastRatio(background, black)) ? white : black
    - return (fallback, Override)

    AdjustAccent(RgbColor background, RgbColor accent):
    - bgLum = RelativeLuminance(background)
    - (h, s, l) = ColorToHsl(accent)  // l in 0–100
    - direction = bgLum > 0.5 ? -1 : +1  // darken on light bg, lighten on dark bg
    - for step = 5; step <= 40; step += 5:
        newL = Math.Clamp(l + direction * step, 0.0, 100.0)
        candidate = HslToColor(h, s, newL, accent.R, accent.G, accent.B)  // preserve alpha-via-byte via RgbColor
        if ContrastRatio(background, candidate) >= 4.5: return candidate
    - return accent  // no suitable adjustment found; caller handles fallback

    ColorToHsl(RgbColor c) -> (double h, double s, double l):
    - Standard RGB-to-HSL. r=R/255.0, g=G/255.0, b=B/255.0
    - max=Math.Max(r,Math.Max(g,b)), min=Math.Min(r,Math.Min(g,b)), delta=max-min
    - l = (max+min)/2.0 * 100.0  // 0–100
    - s = (delta == 0) ? 0 : delta / (1 - Math.Abs(max+min-1)) * 100.0  // 0–100
    - h: if delta==0 → 0; elif max==r → 60*((g-b)/delta % 6); elif max==g → 60*((b-r)/delta+2); else → 60*((r-g)/delta+4)
    - h = (h + 360) % 360

    HslToColor(double h, double s, double l) -> RgbColor:
    - s /= 100.0, l /= 100.0
    - Standard HSL-to-RGB formula using c = (1-|2l-1|)*s, x = c*(1-|(h/60)%2-1|), m = l-c/2
    - Assign r,g,b segments based on hue sextant, then return RgbColor((byte)((r+m)*255), ...)
