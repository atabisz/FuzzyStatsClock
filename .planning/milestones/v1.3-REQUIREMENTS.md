# Requirements: Fuzzy Clock

**Defined:** 2026-02-26
**Core Value:** The time phrase is always visible on the desktop, readable at a glance, with no visual chrome getting in the way.

## v1 Requirements

Requirements for v1.3 release. Each maps to a roadmap phase.

### Stats Visibility

- [x] **STAT-06**: User can toggle CPU row visibility via right-click Stats submenu; checkmark reflects current state each time menu opens ✓ delivered v1.3
- [x] **STAT-07**: User can toggle GPU row visibility via right-click Stats submenu; checkmark reflects current state each time menu opens ✓ delivered v1.3
- [x] **STAT-08**: User can toggle MEM row visibility via right-click Stats submenu; checkmark reflects current state each time menu opens ✓ delivered v1.3
- [x] **STAT-09**: Hiding all three stats individually auto-collapses the stats panel (equivalent to turning Show Stats off) ✓ delivered v1.3
- [x] **STAT-10**: Individual stat visibility (CPU/GPU/MEM) persists to settings.json and restores on launch ✓ delivered v1.3

## Out of Scope

| Feature | Reason |
|---------|--------|
| System tray icon / settings UI | Keep it simple |
| 24-hour format | Natural English implies 12-hour |
| Click-through / no interaction | Incompatible with drag (kills DragMove() event delivery) |
| Arbitrary font size input | 3-step ladder is sufficient |
| Font family selector | Single clean font (Segoe UI Light) is part of the design |
| Reset all stats to visible via Show Stats | Individual toggles are independent; simpler model |
