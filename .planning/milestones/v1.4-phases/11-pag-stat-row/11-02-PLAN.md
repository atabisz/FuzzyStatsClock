**1. Replace stub MenuPagVisible_Click** — find the stub `private void MenuPagVisible_Click(object sender, RoutedEventArgs e) { }` added by Plan 11-01 and replace it with:

```csharp
private void MenuPagVisible_Click(object sender, RoutedEventArgs e)
    => SetStatRowVisible(PagRow, PagRow.Visibility != Visibility.Visible);
```

This reads `PagRow.Visibility` (NOT `IsChecked`) to determine toggle direction — same pattern as MenuCpuVisible_Click, MenuGpuVisible_Click, MenuMemVisible_Click. WPF IsCheckable auto-toggles IsChecked before the handler fires, making IsChecked unreliable for toggle logic.

**2. UpdateStatsDisplay() — add PAG branch** after the `MemBar.Width` line and before the closing brace of UpdateStatsDisplay:

```csharp
        if (_statsService.PagPercent < 0f)
        {
            PagText.Text = "N/A";
            PagBar.Width = 0;
        }
        else
        {
            PagText.Text = $"{_statsService.PagPercent:F0}%";
            PagBar.Width = StatsBarTrackWidth * (_statsService.PagPercent / 100.0);
        }
```

**3. ContextMenu_Opened() — add PAG checkmark** after the `MenuMemVisible.IsChecked` line:

```csharp
        MenuPagVisible.IsChecked = (PagRow.Visibility == Visibility.Visible);
```

**4. ApplySettings() — add PAG row Visibility** after the `MemRow.Visibility` assignment line:

```csharp
        PagRow.Visibility = s.PagVisible ? Visibility.Visible : Visibility.Collapsed;
```

Set directly (NOT via SetStatRowVisible). SetStatRowVisible calls UpdateLayout()+Clamp() which are unsafe before Show() where ActualHeight is 0. This is the established pattern for all row visibility in ApplySettings().

**5. SaveSettings() — add PagVisible field** in the AppSettings object initializer, after the `MemVisible` line. The SaveSettings method after this change:

```csharp
    internal void SaveSettings()
    {
        SettingsService.Save(new AppSettings
        {
            Left = Left,
            Top = Top,
            FontSize = _currentFontSize,
            StatsVisible = (StatsPanel.Visibility == Visibility.Visible),
            StatsIntervalSeconds = _statsIntervalSeconds,
            CpuVisible = (CpuRow.Visibility == Visibility.Visible),
            GpuVisible = (GpuRow.Visibility == Visibility.Visible),
            MemVisible = (MemRow.Visibility == Visibility.Visible),
            PagVisible = (PagRow.Visibility == Visibility.Visible)
        });
    }
```

**6. SetStatRowVisible() — fix auto-collapse to include PagRow**. Find the auto-collapse condition (currently checks 3 rows) and add PagRow:

