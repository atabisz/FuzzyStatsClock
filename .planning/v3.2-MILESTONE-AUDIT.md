### MISS-01: ResetToDefaults() Missing PhraseStyle Reset

- **File:** `FuzzyClock.App/MainWindow.xaml.cs`, `ResetToDefaults()` method
- **Affects:** STYLE-01, STYLE-02, STYLE-03, STYLE-04
- **Severity:** Medium (user-visible functional regression)
- **Detail:** `ResetToDefaults()` calls `SetTextStyle("Classic")` to reset the text layout style but never calls `SetPhraseStyle("Classic")`. After reset: `_currentPhraseStyle` retains prior value (e.g., "Rude"), `PhraseEngine` stays on `en-rude`, Settings combo shows old style on re-open, and `AppSettings.PhraseStyle` is persisted as the stale value across restart.
- **Fix:** Add `SetPhraseStyle("Classic");` inside `ResetToDefaults()`, parallel to the `SetTextStyle("Classic")` call.
